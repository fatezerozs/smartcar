## 今日结论

今天完成了赛道功能合入、速度环补偿与转向联动改进、无线串口原始采集，
并根据视频和日志修复多种误限速及路口识别问题。已有实车反馈确认部分直道、弯道表现改善，
但最新仍反馈行驶中异常降速/迟滞，以及无法驶入右侧与直道相切的圆环。
因此，今天的成果是可继续试车的 C28 候选和可追溯的诊断记录，不能宣布完成整圈验收。

四项优先级保持不变：不驶出赛道；岔路倾向保持当前方向；倾向覆盖全部赛道；尽快完成。
不能以局部提速或主机测试通过，代替完整路线的速度、稳定性与覆盖验证。

## 遇到的问题、改进方法与效果

| 问题 | 今日改进方法 | 最终效果与局限 |
| --- | --- | --- |
| 赛道功能分散在调试分支，main 需要形成可继续迭代的版本 | 合入当前白色通道、单边界恢复、十字连接、圆环状态机、C26 启停及记录功能；将几何、转向混合、动力权限、目标包络分成独立模块 | main 工作树形成 C28，仍由 `midterm_switch` 构建。按功能拆分，避免继续把全部逻辑堆入 `vision_drive.c` |
| 直道和弯道速度偏低，旧输出上限不足以反映真实动力需求 | 先提高动力余量，随后取消循迹固定 40% PWM 限制；区分轮速目标与实际 PWM；保留 PWM 上升斜率、编码器反馈和故障保护 | 用户反馈过直道与弯道有改善。当前闭环可在物理 PWM 范围内按需输出，不能把“允许更大输出”当成实车已提速或制动距离已验证 |
| 差速与舵机命令不一致、加速时两轮暂时趋同 | 使用同一连续转向映射驱动舵机与差速；先限制共同速度包络，再保留左右轮目标比例 | 模拟输出中转向与内外轮方向一致，满转向内轮目标约为外轮 65%。没有转角传感器，不称为精确车辆运动学模型 |
| 前馈偏大时轮速持续高于目标 | 允许 PI 积分有符号抵消前馈，最终仍输出非负 PWM；修正微小目标变化反复削弱积分的问题 | 主机不同轮子响应模型能跟踪目标；真实日志曾出现持续轮速偏差。修正机制通过回归，实车闭环参数仍需对照 |
| 少量外围补线触发整帧爬行 | C27 区分实际控制区域与外围补线，避免仅底部 4 行补线就丢掉真实预瞄和压低目标 | 灰度回归复现旧目标约 18/17 counts/10ms，并验证修正；随后 C28 进一步移除道路标签限速 |
| 路口或圆环状态使道路清晰时也突然降档 | C28 移除路口统一 `.45/.65 × cruise` 需求上限，取消圆环标签对配对道路速度的否决；覆盖率不再被误用为识别正确率 | 同一路径输入的 FOLLOW/EXIT/COOLDOWN 不再仅因标签而退到 base。现场“异常降速”尚不能宣布消除 |
| 速度档切换造成迟滞感或速度波动 | C28 在既有尺度之间连续连接，结合当前/请求转向及横向余量；保留共同目标包络及当前边界验证 | 主机模式边界测试无明显目标跳变。几何调参仍不是实测过弯极限，不以标签或保守档位代替风险证据 |
| 路口丢线、异常停车 | 修复宽视野下偏移导致一侧扩宽落在相机外的情况：允许单侧可见扩宽，但候选中央半宽必须完整可见且当前全白，原有真实锚点与通道验证仍需通过 | 9 组独立偏移/朝向投影组合未再出现该缺陷。全白无锚点、黑色断口与真正丢线仍保留失效处理，未证明所有现场停车均已解决 |
| 右侧相切圆环未驶入 | 已加入闭合/侧裁剪暗岛识别、当前内边界选择、入口白色余量内的引导目标，以及选路无效时的当前道路回退 | 主机相切投影与控制链路可产生朝圆环的转向；用户最新反馈仍无法切入右侧圆环，故该项明确未通过实车验收 |
| 无线日志依赖人工转发、日志容易混入损坏文本 | 新增 COM10 被动原始字节采集、接收时间/偏移、校验值，严格筛选完整字段并保存损坏原件 | 已直接收到 C27 版本输出及轮速、视觉、故障记录。多个启动周期与延迟 TRACE 必须区分；不能把接收时刻当成采样时刻 |
| 电池电压可能影响试车比较 | 记录用户确认的 3S、2200mAh、标称 11.1V、静态实测 10.8V；将负载压降及单体电压列为对照项 | 静态总电压不能排除负载压降或单体差异。没有证据将全部低速归因于电池，也不能凭总电压判定电池故障 |

## 后续需要改进的地方

### 1. 异常降速与迟滞：先区分频率问题和控制需求问题

最新用户反馈：行驶过程中仍有莫名降速及迟滞，怀疑 PWM 频率偏低。
源码当前电机 `VISION_MOTOR_PWM_HZ=17000U`，即 17kHz；舵机 50Hz 是另一路配置，
不能混淆。该数值只说明初始化请求，尚无示波器实测，不把频率作为已确认根因。

下一步先在相同行驶条件下同步记录目标轮速、实测轮速、左右 PWM、视觉路径、
转向请求/命令及故障；实测电机 PWM 的频率、占空比与波形。
若目标先下降，优先查路径判定及速度规划；若目标稳定而反馈下降，查驱动输出、负载及供电；
若输出受限或频繁归零，查 PI、目标包络、输出斜率和反馈时序。
只有硬件驱动规格与测量支持时，再做频率对照，不直接修改频率并宣称解决。

### 2. 右侧与直道相切的圆环：确认未进入的具体阶段

该问题仍未解决，不能用中央回环通过或主机暗岛识别通过来代替。
下一轮在相切入口同步采集板载灰度/二值图、`ring` 状态与方向、入口引导行数、
当前中心线、转向和左右轮目标。依次区分未识别暗岛、进入状态过早被取消、
引导未传到转向、转向跟随不足、实际选择仍留在直道等原因。
改进必须支持真正进入并绕完该圆环，不能只延长一个转向定时器或任意偏置来冒充完成覆盖。

### 3. 继续提高速度，但不恢复标签爬行

先消除不必要的目标下降和迟滞，再比较直线、左右弯、十字与相切圆环的局部通过速度。
在不出界、不漏段、岔路方向正确的前提下继续提高速度。
只有可观察的道路余量不足、转向/轮速跟随失配、出界趋势等证据要求时才收紧对应速度，
不能仅因为“这是弯道/路口”就施加统一低速。
现有几何参数仍需实车标定，不能声称已经证明某个固定速度以上必然出界。

### 4. 剩余故障与全程验收

继续查视觉有效性停车、左轮反向计数及可能的接线/供电问题。
同步相机帧和视频；记录完整路线覆盖、异常停车次数、出界/漏段、局部与整体行驶时间。
多个测试周期、停车后导出的 TRACE 和人工移车阶段必须分开统计。
目前四项总体目标尚未全部完成，整圈成功率和速度提升比例暂不提供。

# B11 蜂鸣器低声高频噪音排查

依据：用户提供的蜂鸣器原理图原图（原布局核对，`pdf_verified` 的等效原图证据）与当前应用源码。没有实测波形；下面的故障原因是待验证假设。所附 `E8_04_ov7725_oled_display_demo/user/src/main.c` 是 OV7725 + OLED 例程，没有蜂鸣器初始化，不能作为本项目 B11 已正确配置的证明。本项目使用 MT9V03X，不替换为该例程的摄像头驱动。

## 电路与本次软件修正

图中蜂鸣器正端从 3V3 经 R17（10Ω）供电；负端由 Q2（S8050）下拉。B11 经 R34（4.7kΩ）连接基极，R35（10kΩ）从 **B11 一侧** 接地。由此判断控制极性：高电平导通，低电平关闭。

旧应用未明确初始化 B11。现在 `main()` 在计时器启动后、UART/300ms 等待/相机处理前调用 `board_io_init()`，将 B11 配置为 GPIO 推挽输出、初始低。`board_buzzer_set(0)` 保持关闭；`board_buzzer_set(1)` 是持续高电平，不产生高频 PWM。正常固件不自动蜂鸣。

这能消除应用阶段引脚未明确配置的问题，但不能保证复位释放前/Boot ROM 阶段的电平，也不能修复硬件损坏。R35 本来已有下拉，因此“没初始化”只是排查线索，不能直接断言 B11 一定悬空。

## 0.55V 能说明什么

B11 是 R34 前的 GPIO 节点，不是 Q2 基极。测得 B11 对地 0.55V 不能等同于测得 VBE=0.55V，也不能证明 Q2 已充分导通。

1. **脉冲的平均值**：万用表可能把高低变化读成中间电压。假设 0/3.3V 波形，0.55/3.3≈16.7%，仅是等效平均占空比计算（`computed`），不是已经测得的占空比。用示波器测 B11。
2. **GPIO 处于输入/内部弱上拉/其他复用状态**：与 R35 等外部负载形成中间电平，可能使驱动处于不确定状态。烧录本次明确拉低的初始化后复测；搜索后续 GPIO/外设初始化是否重新占用该脚。
3. **接触、漏电或器件故障**：核心板未插实、公共地异常、GPIO 损伤、焊接污染、R34/R35 错件或 Q2 漏电。若明确推挽低后仍为 0.55V，优先查这些，而不是提高驱动电平掩盖问题。
4. **供电或声源误判**：3V3 纹波、蜂鸣器件规格不符、器件本身异常，或噪音实际来自电源电感。B11 已低但仍有声音时，需要确认声源与蜂鸣器两端电压。

## 建议测量顺序

1. 用新固件先保持 B11 推挽低，复位后测 B11、Q2 基极、Q2 集电极和 3V3，均以同一电路地为参考。关闭时预期 B11/基极接近 0V、蜂鸣器两端电压接近 0；集电极的具体静态读数还取决于蜂鸣器内部电路。
2. 示波器观察 B11 从上电、复位到程序运行的全过程，并同时看 3V3。区分短暂启动噪音与持续噪音，区分直流中间电平与脉冲平均值。
3. 若 B11 已稳定低而仍响，测 Q2 集电极及蜂鸣器两端；检查 Q2 是否漏电/短路、R17 是否错件、供电纹波和声源。断电后再做阻值、通断及焊点检查。
4. 若 B11 仍被抬高，可在断电后隔离核心板/外设，逐步定位异常来自 MCU 侧还是主板侧。不要在 MCU 正驱动时把 B11 强行短接到地；地电平诊断应通过程序或断电隔离后进行。
5. 关闭正常后，再做受控短时高电平鸣叫试验，同时测基极、集电极与供电。若高电平正常但不响，核对蜂鸣器 BOM、额定电压、极性，以及其为有源还是无源。原理图符号不足以确认类型：有源通常直流触发，无源需要按器件规格驱动，不能据此直接指定频率或更换电阻。

首次复测最有价值的是：**拉低初始化后 B11 的电压、B11 示波器波形、蜂鸣器两端电压**。这些可将软件复用、驱动电路和供电问题分开。

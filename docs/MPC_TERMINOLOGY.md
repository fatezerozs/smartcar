# MPC 文档：术语、缩写和单位索引

本页面向阅读工程说明和回归报告的用户。项目内约定的概念以[领域术语表](../GLOSSARY.md)为准；下面补充通用工程术语、缩写、代码字段与查证位置。首次使用时优先写中文全称，再附缩写；不要把同名信号默认当作同一个量。

维护MPC相关文档时，首次出现的专业术语、缩写和项目内部名称应给出一句解释或链接到本索引；涉及单位、参数或验收结论时同时写明对象和适用范围。优先使用已有通用名称或领域术语表中的名称；确实需要新名称时先说明定义，含义未确认则标为待核对。历史报告的原始数字和当时结论应保留时间与构型，新增解释不能改写其证据。

<a id="planning"></a>
## 规划与运动

| 术语 | 必要解释 |
| --- | --- |
| **MPC** | 通常指模型预测控制（Model Predictive Control）：基于模型预测未来状态并在约束下滚动求解控制问题。`MPC_20261106`也是本工程名称；该名称本身不证明当前速度内核已实现标准MPC优化求解器。当前内核行为见[工作说明](MPC_GUIDE.md#implementation)。 |
| **速度规划器** | 按路径、速度和车辆能力等约束计算速度参考的模块；其输出是目标或候选结果，不等于车轮的实测速度。 |
| **路径预瞄（preview）/ 预瞄范围（horizon）** | 前方一组有序路径点，以及规划时采用的这段可信范围。不要与供人查看的缩小预览图区分不清；路径点测量和坐标来源必须说明。 |
| **曲率（curvature，κ）** | 路径弯曲程度；米制平面曲率单位为1/m。半径为R的圆弧，其曲率大小为1/R；本项目米制坐标约定右转曲率为正。 |
| **侧向加速度（lateral acceleration）** | 转弯时指向路径弯曲方向的加速度，单位m/s²；可用于给弯道速度设置约束。 |
| **限速 / cap / `current_cap`** | 对允许速度设置的上界；当前内核的`current_cap`是当前位置的几何限速。不要把它与请求速度、轨迹当前速度或实测速度混为一谈。 |
| **加加速度（jerk）** | 加速度随时间的变化率，单位m/s³；限制它是为了约束速度参考变化的平滑程度。参考曲线平滑不自动证明实车速度平滑。 |
| **速度参考整形（shaping）** | 根据目标速度、当前速度参考和动态约束，逐周期计算新的速度与加速度参考。 |
| **制动能力（brake）** | 用于计算减速能力的参数或实测能力，通常以m/s²表示；模拟参考值、候选值与经验证的实车能力必须区分。 |
| **余量（margin）** | 为未建模距离或误差预留的量；应说明来源和适用范围，不能将任意数值称为已验证的安全裕量。 |
| **不可行（infeasible）** | 当前状态与约束无法同时满足的计算结果；本项目相关规划接口拒绝该候选并交由监督处理。它不是实际刹车距离已经满足要求的证明。 |

<a id="vision"></a>
## 视觉与运行状态

| 术语 | 必要解释 |
| --- | --- |
| **near / far / full** | 英文分别表示近、远、完整；必须加模块前缀。旧控制器near/far是视觉控制观察，米制规划器near/full是两组独立路径预瞄；规划器代码中的`far_valid`表示完整预瞄有效。详见[对应关系](MPC_GUIDE.md#near-full)。 |
| **`row_flags`** | 图像某行道路证据类型：`0`无有效行，`1`或`2`为单边推算，`3`为真实双边，`4`为路口补线。它不是准确率或置信概率。 |
| **置信度（confidence）** | 视觉结果给出的质量分数；其含义和阈值取决于实现，不能直接当作正确概率。 |
| **灰度、阈值、二值图** | 灰度表示像素明暗；阈值用于按亮度分类；二值图是分类后的黑白图。灰地面亮度接近白赛道时可能被错误合并。 |
| **ROI（Region of Interest）** | 感兴趣区域，即算法选取进行特定处理或统计的图像范围；报告需说明范围及分辨率。 |
| **单应矩阵（homography）** | 在特定平面和相机条件下，将图像坐标映射到另一坐标系的3×3矩阵；候选标定的结果不自动适用于其他相机安装或离开该平面的物体。 |
| **环岛状态** | 视觉/路线模块对当前环岛过程的阶段判断，如进岛、环内、出岛和恢复；识别阶段正确不等于车辆已成功绕行。 |
| **影子模式（shadow）** | 新链路只生成用于核查的结果，不因该结果自动取得电机权限；与板载实际运行版本、主动接管分别标识。 |
| **监督器（supervisor）** | 依据输入有效性、时间/距离预算和故障状态决定运行、降级、停机或锁存的逻辑。 |
| **受控停止 / 立即清零 / 锁存** | 受控停止使用受约束的速度参考趋向零；立即清零是禁止并清除相关目标/输出；锁存是在停止或故障后保持状态，直到满足重新准入条件。实际执行行为以对应构型为准。 |
| **capture / 帧序号 / 时间对齐** | capture是图像采集时刻；帧序号区分图像；时间对齐把图像与同一时刻或经允许插值的编码器信息对应。处理时间不应冒充采集时间。 |
| **预算（budget）/ 期限（deadline）** | 本项目常用时间或路程限制一段降级或恢复过程；到期后的处理由相应监督状态和配置决定，并非泛指性能预算。 |
| **地面适用域（ground domain）** | 一组坐标范围，米制适配器用它筛选投影路径点；配置中的范围不自动构成经过实车验证的有效区域。 |
| **大津法（Otsu）** | 根据图像灰度分布选择分割阈值的方法；多种亮度区域混合时，选出的阈值不保证恰好分开赛道和地面。 |
| **候选结果 / 身份版本（revision、generation、epoch）** | 候选结果是等待检查或采用的输出；版本、代数和周期标识用来区分配置或运行状态，具体匹配规则须查对应接口，不能只凭数值相同证明物理标定正确。 |

<a id="measurement"></a>
## 计量与控制

| 术语 | 必要解释 |
| --- | --- |
| **tick / count / tics** | 这里指编码器计数；`tics`是历史拼写，优先写“计数（ticks）”，不能不经换算就称作米或秒。左右轮的方向和尺度应分别说明。 |
| **ticks/10ms** | 每10毫秒的编码器计数，是本工程轮速接口的单位。全程120 ticks/10ms是完整运行窗口的平均目标，包含起步、减速和窗口内停顿；不是每个10ms都要达到120，也不是地面速度的保证。 |
| **ticks/s、ticks/m、m/s** | 分别为每秒计数、每米计数、每秒米数；换算依赖实际时间及经说明的轮端距离尺度。每秒计数除以100可得到等效每10ms计数；计数速度受打滑影响。 |
| **CPR（counts per revolution）** | 每转计数；需说明测量位置、编码器计数方式及对应左右轮。它与负载下的每米计数不是同一个标定量。 |
| **编码器（encoder）** | 测量轮轴旋转并输出计数的传感器；计数与方向用于推算轮速和轮端路程。 |
| **里程计（odometry）/ 轮端路程** | 根据轮子转动等传感信息估算运动距离或状态的方法/结果；存在打滑、轮径及采样等误差。 |
| **PI（Proportional–Integral）控制** | 根据目标与反馈的偏差，组合比例项和积分项来计算控制量；本项目分左右轮使用，参数和物理效果需单独验证。 |
| **PWM（Pulse Width Modulation）** | 脉宽调制，通过脉冲占空比控制驱动输出；占空比或PWM命令不等同实际电机转矩、车速或地面速度。 |
| **前馈（feedforward）** | 根据目标或模型预先给出的控制量，用于补充反馈控制；来源、单位及是否实际启用应明确。 |

<a id="validation"></a>
## 测试与证据

| 术语 | 必要解释 |
| --- | --- |
| **Host（主机）** | 开发计算机或其测试环境；主机执行耗时不等于车载芯片执行耗时。 |
| **回归测试（regression test）** | 修改前后重复执行的检查，用于发现既有行为受影响；测试通过只覆盖明确列出的场景、数据和构型。 |
| **真实原图 / 合成图 / 派生图** | 原图来自实际相机记录；合成图由程序构造；派生图由已有图像变换得到，如镜像或放大。要标明分辨率、来源与是否独立样本。 |
| **真值（ground truth）/ 参考标注** | 用于比较识别结果的参考答案；应说明标注方法、范围、精度及是否独立，局部标注不代表全图真值。 |
| **IoU（Intersection over Union）** | 交并比：预测区域与参考区域的交集面积除以并集面积。必须说明所比较的类别、区域与样本；合成图IoU不等于实拍准确率。 |
| **P95 / P99** | 第95/99百分位；例如P95耗时表示约95%的本组样本耗时不高于该值，不能替代最大耗时或板端最坏情况。 |
| **WCET（Worst-Case Execution Time）** | 最坏情况执行时间，是在明确硬件、输入和执行条件下的时间上界；主机样本最大值不自动构成该上界。 |
| **基线（baseline）/ A/B对照** | 基线是明确身份和条件的比较对象；A/B对照在可比条件下比较两种方案。输入、版本或设备不一致时不能简单归因改进或退化。 |
| **固件（firmware）/ 目标板 / 烧录** | 固件是运行在设备上的软件；目标板是实际设备电路板；烧录是将固件写入设备。源码、构建文件和已烧录固件可能不是同一版本。 |
| **MSVC / GCC / ASan / CI** | MSVC和GCC是不同的编译工具链；ASan是地址错误检测工具；CI是持续集成，即自动执行构建和检查的流程。工具通过不扩展其测试范围。 |
| **验收** | 按预先说明的对象、条件、指标与证据判断是否满足要求；软件测试、目标板时序和完整实车赛道验收应分别说明。 |
| **软件PASS / 场景验收 / 放行资格** | 软件PASS表示测试断言通过；统一结果中的`acceptance`另存声明场景的通过、未就绪、未执行或证据错误；`releaseEligible`是受测试范围、工具链和场景状态共同限制的软件资格，不授予实际电机权限。详见[报告字段说明](TESTING_FRAMEWORK_GUIDE.md#83-软件通过场景验收与放行资格)。 |
| **候选值 / 实测值 / 生产参数** | 候选值是待核定方案；实测值来自注明条件的测量；生产参数是被正式采用的运行配置。实测或候选不自动取得生产采用资格。 |

<a id="identifiers"></a>
## 阶段、构型与工具

| 术语 | 必要解释 |
| --- | --- |
| **Phase 2 / Phase 3 / Phase 4** | 本项目阶段标签：相应历史报告分别讨论数据采集与标定、规划链路接入和后续追溯/赛道验证；每篇文档按其日期和具体范围解释，不因阶段名称默认验收完成。 |
| **C26 / C31 / C32** | 本项目不同固件或工作阶段的历史标识，具体含义取决于上下文；报告应给出完整固件身份、构型及版本，不能只用数字推断已上板。 |
| **V4** | 某次Phase 3影子候选的版本标签；应与其固件身份和报告日期一起使用，不等于当前全部工作区代码。 |
| **Keil / ARM / MCU / RT1064** | Keil是嵌入式开发与构建工具；ARM指相关处理器架构/工具链；MCU是微控制器；RT1064是本车使用的微控制器型号。构建通过不等于已烧录或通过实车测试。 |
| **IRQ / ISR** | IRQ是中断请求，ISR是响应中断的程序；并发、数据所有权和时间限制需要针对目标板验证。 |
| **CRC / SHA-256** | CRC是循环冗余校验，常用于检测传输或记录错误；SHA-256是哈希算法，常用于核对文件身份。校验一致不能证明数据本身标注正确。 |
| **回放（replay）/ 夹具（fixture）** | 回放是按记录或明确规则重新输入数据执行软件；夹具是测试使用的固定输入或环境。二者需标明真实、合成、混合以及时间模型。 |

索引中的通用概念采用通常工程含义；本项目具体行为以[工作说明](MPC_GUIDE.md)、相应源码和注明版本的原始报告为准。索引不是对任何参数、车型或实车性能的认证。

# 先建立 R13 行为的轻量赛道基线

首版采用支持 MPC 接入的职责与数据 Interface，以 R13 的控制行为作为初始实现，R4 等候选作为并发、连续性和故障处理的参考，先形成可逐步验证的轻量工程，再替换内部算法。这样先获得可比较的完整运行基线，避免把尚未成熟的米制主动准入和多套动力决策同时带入首版。该分期不等于完整 MPC 优化器已实现；[ADR-0001](0001-planner-near-authority.md)保留为后续米制 CONTROL 的目标设计。

完整赛道按[用户原图与提案](../changes/planner-authority-design-20261111/MINIMAL_TRACK_PROPOSAL.md)定义：A 出发，按红线方向到 B，再完成其余道路回到 A；中央与右上两处环形各绕一圈，全程连续完成，不能用多次重新起跑拼成全程。环岛进出与出环重获属于首版必需能力，R13 现有经验不足以证明这些能力已经通过。

用户已确认允许已知赛道元素顺序辅助识别，以减少误入与重复入环；元素进入、退出仍需当前视觉证据，不能仅按固定时间或轮程盲目转弯。首版保留 R13 的 C26 物理开关启动/停止方式，将上电自动运行、双固件与参数持久化后置；[已确认的自动运行设计](../changes/metric-control-experiment-20261111/POWER_CYCLE_CONFIGURATION_DESIGN.md)继续作为后续目标，不视为已取消。

本记录仅确认分期与赛道目标；未修改固件源码、取消原 STOP/严重故障保护或执行硬件操作。来源为本轮用户逐项确认与原图直接查看，未将图纸标注当成实物测量。

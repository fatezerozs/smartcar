# 贝叶斯赛道估计与中期开环驱动

日期：2026-10-18。基线提交：`eb5ed00`。本文描述当前工作区重构，不代表已经提交/推送或实车验收完成。

## 两条路径及边界

- `f`：完整赛道观测。12 个隐状态为 UNKNOWN、直道、左右弯、十字、斑马线及左右环岛入口/环内/出口。完整模式禁止驱动，避免用中期算法强行过环岛。
- `m`：中期模式。摄像头闭环控制转向，电机使用独立的开环 PWM 模块，不读取编码器。实际输出还须标定确认、人工解锁及安全租约，默认禁用。

中期文档要求沿直道和弯道从 A 到 B 或反向，不经过环岛/十字，不要求自动停车，摄像头组不放红砖。因此未添加固定终点坐标、第二次斑马线停车或定时转弯。

**完整赛道状态估计不是完整赛道自动导航。** 默认模型是未训练专家初值；环岛补线、十字分支选择、完整路线规划尚未实现和验证，不宣称整圈已可跑。合成状态均值测试只能证明代码遵循模型，不能证明真实环岛识别正确。

## 贝叶斯模型与置信算法

六维特征：近远方向差、近中远二阶变化、左右图像边缘开放比例、多个白色通道的行比例、额外黑白跳变密度。几何只用双边实测行，扣除两点安装参考轴，以道路半宽归一化；拓扑来自 ROI 二值图，不使用人为补线作为识别证据。

缺失特征用 mask 标识，不以零代入似然。quality 是对比度形成的观测质量，不是分类正确概率。核心递推：

```text
mix = 1-exp(-dt/dwell_s)
T(dt) = (1-mix)*I + mix*A
prediction(j) = sum_i posterior_previous(i)*T(i,j)
posterior(j) ∝ prediction(j)*likelihood(x|j)^(quality*min(dt/evidence_s,1))
```

似然使用对角高斯，在 log 域计算并减去最大值后指数归一化。时间尺度减弱相关帧的重复证据，不用于按秒推进赛道步骤。环岛拓扑先验允许拒识和恢复，不把误判锁成不可退出的吸收态。

- candidate 是最大后验候选；state 只有拒识检查通过才有效，否则 UNKNOWN。
- p 是候选后验，不是实测正确率；margin 是第一、第二候选概率差。
- entropy 是归一化熵。accepted 同时要求最大后验、概率差、熵及平均马氏距离合格。
- trained=0 是专家初值；trained=1 只代表应用了标注拟合参数，仍不等于现场验证通过。
- 原 VISION2 的 q 是行覆盖分数，不能与贝叶斯后验混为一谈。

重复帧不累积证据；倒序、同毫秒伪新帧和异常观测拒识；坏帧保留消费序号防重复；断流清除旧后验。无符号时间差支持正常 32 位回绕，显式 r 重置完整历史。安全 DISARMED/RUNNING/FAULT 仍是确定性状态机，不能被高后验解除。

## 安装偏移与可替换模型

近/远两点参考轴只补偿横向偏移及偏航的近似，不能代替畸变、滚转和任意俯仰校准。仅在确认居中、朝向正确的直道标定，不在未知弯道自动归零。

tb_init 校验概率、方差、时间尺度与几何范围，并按值保存模型。非法模型保持 UNKNOWN。默认参数集中在 tb_default_model；工具 tools/fit_track_model.py 可从人工标注序列估计均值、带下限方差、平滑先验与转移矩阵，CSV 表头为：

```text
sequence,ms,state,heading,curvature,open_left,open_right,split,stripes
```

sequence 是录制 ID；同一录制 ms 严格递增；state 使用串口名称；缺失特征留空。FEATURE 日志提供帧号、时间、mask 和特征；重复日志需按帧去重，mask 缺失项不可当真实零值。不能把模型自身输出当作人工标签。

开发者示例：`python tools/fit_track_model.py labelled.csv candidate_model.h`。工具拒绝覆盖已有文件，默认每类每特征至少 20 个有效样本；这只是最低输入条件，不保证数据足够。按整段录制划分训练/验证集，不把相邻帧随机拆分后宣称泛化。

候选模型经过人工审核和留出集验证后，保存为 demo/code/track_model_fitted.h，并显式设置 VISION_BAYES_FITTED_MODEL=1。生成文件须和配置一起管理。脚本不会修改默认配置或打开电机。拒识门限、时间尺度、相机轴仍需独立校准。本次没有真实标签，不伪造训练结果。

## 中期电机开环与安全

vision_control 根据归一化横向误差 e、远近方向差 h 和真实 dt 的滤波 PD 计算转向，有限幅和变化率约束。midterm_open_loop 单独计算电机：

```text
difficulty = w_lateral*abs(e)+w_heading*abs(h)+w_steering*abs(steer)
target = cruise_pwm*coverage/(1+difficulty)
```

远处无观测按配置降额，目标不超过 cap；加速限斜率、减速立即生效。非有限输入或非法配置返回失败，上层锁存故障。它不测实际车速、里程，不能保证恒速或停车距离。无电流/电压/轮速反馈时不能声称已检测堵转、过流、低压或打滑。

a 仅在中期文字模式、标定/硬件确认及连续有效帧满足时解锁；h 续指令租约；s 停止；c 清故障后还须重新积累证据和人工解锁。g/b/o/p/r/f/m 均先停车。同一批接收命令含停止或模式切换时，后面的 a 也不能重新启动。恢复图像不能自动恢复运动。PIT1 仍独立撤销超时输出，但不是关中断卡死情况下的硬件看门狗。

## UART 与预设中断

VISION_WIRELESS_UART_ENABLE=0 使用原 debug UART1。设为 1 时，运行期命令、文字、V2 图传统一走原库 UART8 FIFO/回调，不混合两个来源的心跳。上电初始化错误仍可在 debug 口查看。无线引脚沿用原库 D16/D17、RTS D26，必须核实接线，不自动修改 SDK。

f/m 保持当前显示模式，因此在图传模式也不插入文字。t 返回文字查看 BAYES。V2 十二字节头和 94×60 负载不变。图传为阻塞静态调试，进入前必须停车，不用于驾驶。

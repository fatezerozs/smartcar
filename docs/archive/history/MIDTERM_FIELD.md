## 现场次序

1. 接好下载器、供电并烧录新固件，确认下载/校验结果；烧录后只按 RST。
2. 逐飞助手断开端口但保留 USB；由助手识别当前 COM 并读取，不固定 COM10/COM14。
3. 小车静止在确认笔直的赛道中间，车身朝向赛道。先抓灰度/叠加图，确认采样行位于白色通道内，不在地平线/行人上；可停车用 @bands 调整，再读取 CAL 的 near_x/far_x。valid=1 且 far_ok=1 且图像确认正确时才能用于两点参考轴。不能在弯道标定，也不把室内桌面当成车道。
4. 确认舵机中位脉宽、窄范围端点和正方向，以及电机前进极性。旧宏的角度不直接等于脉宽，也不作为本次自动确认值。必要时先架空车轮，由操作者观察转向/电机方向。
5. 停车设置参数，读回配置；先做短距离低占空比测试，操作者确认可以运动后才发 a。运行需要 h 心跳，不用图传驾驶。
6. 助手读取 RUN 曲线，结合实际偏向/振荡逐次调整 Kp、Kd、方向项和 PWM，最后再确认整段路线。没有编码器时不能由 PWM 推算可靠实测车速。

当前通信状态（2026-10-19）：用户已烧录，COM9 的 BOOT 四阶段、@bands 帮助及读回证实新功能运行，相机约 44～46fps。已在 RAM 试设行带 0.86/0.68/0.035，连续观测 valid=1/far_ok=1，未校准航向差约 -0.15～-0.18；近点约 0.397～0.405、远点约 0.380～0.407。它们与此前摆位不同，待操作者重新确认居中朝向后才能用于 @camera。未配置执行器、未发送 a/h，没有运动。不能复用本次坐标作为所有安装的默认参数；RST 会丢弃本次行带。

## 停车调参协议

普通字符模式发送，关闭 HEX，整行以换行结束。数字中的小数点使用英文点。@ 一到就停车；指令分段接收、超长、超时及非法值均处理，内容不落入旧 a/h/s 控制。成功也不自动发车，必须重新积累有效帧并单独 a。

| 命令格式 | 含义 |
| --- | --- |
| @status | 读回固件版本、标定状态、脉宽、增益、PWM、参考轴、运行租约 |
| @gain Kp Kd Kh | 调整横向、滤波微分和方向项增益 |
| @motor cruise cap rise | 电机目标/上限，均为 0～1 比例；rise 为每秒上升比例 |
| @camera near_x far_x | 写入已确认居中直道的两点轴，归一化到 0～1，并确认相机标定 |
| @bands near_y far_y half | 近/远采样行及半带高，按整幅图像高度归一化；必须在 ROI 内、不重叠。更新后清除相机标定确认，必须重新 @camera |
| @servo center_us min_us max_us sign | 写入已实测的脉宽和正转向符号 ±1，并确认硬件参数 |
| @duration milliseconds | 单次运行租约，100～60000ms；安全超时，不是按时间走路线 |
| ! 或 Ctrl-C | 在任何解析状态立即请求停车 |

表中 Kp、cruise 等为占位说明，不可原样发送。参数全部仅存在 RAM；复位回到未配置值。非法整行不部分覆盖参数；锁存故障必须先单独 c 清除，改参数不能清故障。@servo 的确认要求操作者已核实实际舵机和方向，软件不能验证机械安装。

例如 @gain 0.60 0.025 0.35 是当前初始增益的重写，不是已完成场地调参的保证。不提供猜测的实车脉宽和起步占空比。默认运行租约 5000ms；准备整段路线时可停车设置更合适上限。PIT1 与前台使用同一个已验证的运行上限；相机 100ms、心跳 500ms 租约不开放串口放宽。

参数提交会清除旧帧资格。f/m、图传、暂停及复位仍先停车；完整赛道模式仍只观测。参数协议只在文字模式回复，保持原 V2 图传不混入文字。

@status 另输出 [BANDS] 实际采样行。行带为安装/场地标定参数，不是赛道路线硬编码；不要把某次地平线或截图坐标作为所有安装的默认值。调整不会自动追随每帧噪声，也不会制造远处测量。贝叶斯几何提取与控制器同步使用这些行带。当前未训练模型只显示 candidate，不确认环岛/十字。

## 串口记录工具（由助手运行即可）

tools/field_serial.ps1 无第三方依赖，支持枚举、只读、文字诊断、逐条配置与有界试跑。默认只读，DTR/RTS 关闭，不复位板卡；日志在 .build/field。端口被逐飞助手占用时须先断开逐飞助手。运行时不应同时被两个程序控制。

tools/capture_vision.ps1 -Port COM9 -Mode g（也支持 b/o）先停车，按精确 V2 头抓取一帧。保存 .gray 原始 94×60 预览像素、同尺寸 PNG 和 8 倍最近邻 preview.png；不是算法输入的完整 188×120 原始帧。退出恢复文字模式，不发送 a/h。抓图时可能因阻塞发送降低算法帧率，不作为行驶模式。

开发者接口：-ListPorts 列出端口；-Port COMn -TextMode -Seconds 6 先停并请求帮助/文字后记录。-Command 接受严格的 @ 参数行，先验证新固件标记和每条 ACK。-RunSeconds 必须额外显式 -TrackReady，确认配置 ready=1、运行租约足够且操作者已准备后才解锁，100ms 发送一次 h，到期/异常发送 !s；未做实机连通验证前不得自动使用该分支。

行驶时 RUN 短日志目标为最多 20Hz，内容有帧号、毫秒、横向误差 e、方向差 h、转向 u、电机 PWM、覆盖 q 与帧龄。原多行视觉/贝叶斯诊断暂停，停车后恢复，避免低速串口占满控制周期。它是尽力输出，不保证每个处理帧均记录。

# 中期自主运行实施与验证

## 提交时的已知实车基线

ENCODER_SPEED_DIAG_5已由用户确认直线、主动停止、失联停止、人工确认后倒退/往复、左右短圆弧正常。
成功速度配置为@encoder_sign -1 1、@speed_cfg 40 1 0.05（实际Ki=0.046875）、@balance 1 1、
@motor 0 0.15 0.1；电机前进DIR=1/1，舵机中位1550、范围1500～1600µs。
最新实测1525右转、1575左转；旧文档中相反标注作废。视觉控制sign仍须架空核对，不由固定脉宽测试替代。
这些记录作为源速度配置和训练版人工恢复依据，不把运动诊断验收等同于自主循迹验收。

编码器3左轮、4右轮及落地速度环为已成功基础；旧ENCODER_SPEED文档中的待复测不是最新状态。
2026-10-20晚经用户授权已通过COM10完成静态相机标定和偏差方向检查，未由助手烧录、驱动车辆或修改实车Flash。
静态结果与原始日志索引见[MIDTERM_STAGE1](MIDTERM_STAGE1.md)，相机标定仅RAM，实际舵机纠偏及动态循迹仍待验证。

## 已实现的边界

- 训练与验收共享原视觉、控制器和速度环，独立生成MIDTERM_TRAIN_1与MIDTERM_AUTO_1工程及产物，原速度诊断工程不覆盖。
- 自主版从主控GPT计时起3秒一次性启动；没有C12、C26/C27或远程心跳的启动依赖。物理拨码在自主版不选档；训练版保持原拨码。
- 倒计时短鸣，成功启动长鸣200ms；阻止/取消/停车后短鸣3次。蜂鸣由前台非阻塞更新，前台卡死时不保证提示波形。
- 到期需要完整有效车辆/相机配置、连续有效图像、已确认视觉检查、已确认速度配置、使能的速度环、新鲜编码器样本和无故障。初始化超过3秒直接阻止；到期失败不迟到补启动。
- STOP、故障或运行超时后，本次主控启动周期不会再次自主发车。自主版不接受无线启动/清故障/调参；可选串口输入只会取消运行，不是启动依赖。
- 车辆配置继续使用现有CRC存储；加载不会伪造相机标定。自主版固定使用3000ms，不使用历史Flash中的2秒/C12启动授权。
- 前台在相机帧之间消费编码器样本并更新速度输出；ISR保留10ms采样和超时撤输出，不在ISR算PI。PWM目标变化才写入，停车强制清零并清积分。实际更新周期仍需实车验证。
- 训练运行中约10Hz输出RUN及SPEED；SPEED增加板端ms和采样序号。运动时接收周期遥测，不发送会停车的@status查询。自主版不输出周期日志、图传或训练报告。

## 当前仍然锁定的项目

配置入口为demo/code/midterm_profile.h。逐步实施第一阶段已将实测符号-1/+1、40/1/0.05和MIDTERM_SPEED_CONFIRMED=1写入源配置。
MIDTERM_VISUAL_REVIEWED仍为0；静态相机轴和平移/航向偏差符号已核对，实体舵机视觉纠偏方向尚未核对，自主版仍不会发车。训练版仍需串口配置/启用速度环。

用户指定demo/mdk/diagnostics/encoder_speed.uvprojx用于核对。已检查：它只定义VISION_ENCODER_ENABLE、VISION_MOTION_DIAG、VISION_MOTOR_THRESHOLD_DIAG等编译入口，引用共同源码；工程XML没有保存UART RAM中的max_ticks/Kp/Ki。vision_drive_init重置速度状态，原Flash车辆配置也不序列化速度配置。因此不能声称旧速度参数已从该工程自动恢复，更不能把历史试验20/1/0.05直接标成成功值。

源速度参数已按本次成功实测填写；安装变化后必须重新核对。训练版停车仍应读回实际RAM配置：

- MIDTERM_ENCODER_LEFT_SIGN、MIDTERM_ENCODER_RIGHT_SIGN
- MIDTERM_SPEED_MAX_TICKS、MIDTERM_SPEED_KP、MIDTERM_SPEED_KI
- MIDTERM_SPEED_CONFIRMED=1

这些是速度配置，不是相机/车辆配置。车辆cap/cruise、舵机中位/窗口、方向、配比1/1、相机轴及运行上限仍需通过训练版配置并明确@save，或在经过审核的源配置中提供。车辆正式默认值仍为零，视觉确认位仍为0。配置CRC恢复失败时保持阻止。速度配置修改后须重建，不变更现有Flash记录格式。

MIDTERM_VISUAL_REVIEWED只有静态相机轴标定和架空最终纠偏方向两项完成后才能设1。编译/主机模拟通过不代表这些实车检查通过。

## 分阶段实车验证

每项由现场操作者完成并保存结果；助手的离线测试不替代实测。先保持训练固件，避免未准备好时启用自动启动。

| 阶段 | 操作 | 通过条件与记录 |
| --- | --- | --- |
| 基线 | 核对成功速度配置、固件和车轮映射 | 参数可恢复，记录版本与配置；不重新猜测PI |
| 静态视觉 | 真直道居中摆正，停车用g/o采灰度/叠线；连续观察近远点后@camera标定 | 实际左右边界和采样行正确；左右平移、偏转后的偏差方向正确；保存车辆配置 |
| 视觉转向 | 驱动轮架空，低目标速度；在训练模式显式启动并保持心跳，人工改变相对赛道姿态 | 车偏左时前轮朝右纠偏，反之亦然；姿态恢复后回中，无超机械窗口；随后停止 |
| 直道 | 保持速度环参数，低速短跑，约10Hz采集RUN/SPEED与配置版本 | 连续3次通过所选直道，无故障、持续摆动或长期PWM饱和；记录实际误差和速度，阈值按现场结果确定 |
| 弯道 | 左弯、右弯、连续反向弯分别短跑 | 各连续3次通过，不失线；先降速再处理滞后，不盲目加增益；是否需要内外轮差速由实测决定 |
| 全路线 | 无线训练完整A到B | 连续3次完成，记录用时、故障、轨迹和停止滑行距离；不要求识别红线停车 |
| 配置恢复 | 停车保存车辆参数；核对速度源配置，训练版复位读回 | 车辆配置与预期一致；速度源配置版本对应成功记录；不能把@save当作速度参数已保存 |
| 自主锁定 | 保持任一确认位0，架空验证自主版 | 3秒前后电机都不运动，提示阻止；后来图像变好也不启动 |
| 自主就绪 | 两项实车检查通过才填写确认位，架空验证 | 3秒前零输出；条件合格一次启动；不发送h仍运行；断开无线不影响闭环 |
| 自主异常 | 架空验证相机断流、运行限时及选配串口STOP | 撤输出、清积分、锁存；恢复图像或发送h/a不重启 |
| 正式路线 | 先驱动供电，再给主控上电；人员在3秒内撤离，独立动力开关就绪 | 无线不参与运行；完成A到B，到线后允许人工截停 |

图像工具capture_vision.ps1会先停车，得到94x60预览，不是188x120算法原帧。不要在动态训练中调用它期待无干扰录像，也不要用同一串口同时收图和解析文字。静态图与动态遥测分别保存，按试验编号和配置版本关联；本轮没有宣称已实现同步全帧录像或自动模型训练。

## 只断驱动电源时的操作规则

当前没有驱动供电检测信号。主控不能识别动力开关断开，也不能保证短暂断电恢复时不重起；编码器无反馈故障不能替代供电检测。截停后结束本次运行：先关闭主控，再恢复驱动供电，最后重新给主控上电。严禁让主控保持运行并直接恢复驱动供电。PWM零是撤驱动力，不是保证机械制动。

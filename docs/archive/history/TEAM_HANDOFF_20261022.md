# 2026-10-22 有效成果、C26_19 与接手入口

本次整理从 C26_17 实车运行记录继续，交付 C26_19 源码与固件。C26_18 是夜间未完成视野裁切识别的中间候选；C26_19 补上这一缺口。没有把软件测试通过写成实车完整赛道通过。

## 使用与复现

使用 `demo/mdk/competition/midterm_switch.uvprojx`，目标 `nor_sdram_zf_dtcm`。也可运行 `tools/build_midterm.ps1 -Variant switch -UV4 <本机UV4.exe路径>` 重新生成并全量编译。源工程和 SDK 一并在仓库中，Keil/设备包需本机已有。

用户手动烧录。C26 OFF 撤电机/舵机输出、清环岛状态；C26 ON 在硬件准备好且连续五帧有效赛道后自动开始，C27 忽略。正常行驶无总时限，可 A→B→右侧赛道→A 连续跑；视觉重获后可自动恢复。故障、断帧及显式 STOP 的原有处理仍在。

`releases/MIDTERM_C26_19/` 是这次待实车验证的固件、校验和及构建说明；`releases/MIDTERM_C26_17/` 是已收集真实运行记录的旧固件备份。旧版源码参数应从历史记录理解，不能用当前 C19 工程重编译后声称得到原 C17 二进制。

## 已有有效实车进展

- 用户视频显示已能过第一个弯，并继续通过多个弯道、中央十字和中央回环；后续仍出现贴边、出十字后停滞、长直道慢和最右圆岛沿主线绕过的问题。尚无完整环岛/连续整圈验收。
- C26_17 无线记录确认是视觉故障，不是总运行时限或编码器故障：一次有效弯道舵量约 .779，随后只剩17行单边、覆盖19%，原300ms窗口到期停车；另一处是覆盖逐步下降后停车。日志内计时与外部视频没有统一起点，不做严格逐帧对应。
- 有一份完整的1024项车载导出，覆盖约94.398秒（包括停车/恢复间隔，不是连续行驶时长），另七份导出不完整。`evidence/20261022/c26-17-run-summary.json` 和 `trace-008-run-1.csv` 保留数值证据；没有把不完整导出当成完整实验。

## C26_19 代码成果

1. 近端居中与当前白路优先、单边半宽中线、1430..1670us 渐进舵量及内轮差速保留。清楚且居中的稳态弯外轮需求约由 C17 的23提高到29计数/10ms；该增幅是指令量，尚无 C19 实测速度。
2. 长直道必须连续400ms双边清楚且近远端居中，才渐增到约47计数/10ms。遇弯/十字/证据下降同帧撤销直道提速。速度标度上限50、PWM上限18%；大偏移、缺远端和丢线阶段继续低速。
3. 对出十字后的当前单边片段保留部分最近曲率，避免片段近轴就提前回正。持续当前证据至少八行/足够跨度时低速引导最多1200ms；完全无当前证据仍最多300ms，断帧检查不变。
4. 环岛 ENTER→FOLLOW→EXIT→COOLDOWN 由当前岛侧边、白色连通及新出口证据推进。最右岛位于北行车左，选择暗芯右侧白带，让岛留在车左。没有按地图秒数或固定左右舵顺序运行。
5. C18 的完整暗芯条件在合理透视中会因左侧超出画面而失效。C19 允许仅岛侧横向裁切：必须看见上下封口、内侧明显拱起、当前道路连通、符合宽度的白带和近乎直线的外侧主线边；连续五帧才确认。只看到单侧变白、细黑连接线、上下边界截断不触发。
6. 中央270°回环也可能识别成岛形元素；ENTER 保留近处已验证的十字白区桥接。出岛需外侧新开口与八行当前顺向窄出口、逐行白色通道；跟随状态遇持续普通直路/明确相反弯会撤掉旧岛侧，防止误识别长期影响后续路线。

环岛字段 `ring=0/1/2/3/4` 对应上述状态，`ring_side=-1/+1` 为左/右岛，`ring_rows` 是当前岛侧边支持行。当前控制与原完整赛道贝叶斯观察模块不同，不将未训练分类器的概率当作已完成导航。

## 验证与限制

Keil 全量编译0错误0警告；C26启停297347项、真实灰度至执行器227567项、环岛230项、24组地图透视/镜像进岛1203项、完整应用运行及 ASAN 通过，普通主机测试也通过。固件精确 SHA256、程序大小和日志见对应 release 目录。

地图回放用公开的几何坐标与一组近似透视参数，未标定相机姿态，固定车姿不服从转向输出，只验证候选进入与方向。更短纵向视野可能连上下封口也看不全，此时仍不会强行判断为环岛。这是保留的识别限制，不能声称24组测试代表所有实际安装，更不能声称已经模拟完成一圈。

接下来使用用户正常跑车视频及被动无线记录判断 C19 的真实入岛、过弯和出岛效果，不要求反复静态摆放或架空。若仍漏入岛，优先检查 `ring` 状态与当时相机画面；若已 FOLLOW 却转不过，结合舵机饱和、近远偏差、轮速再改。尚未完成物理路线验收。

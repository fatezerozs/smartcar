## 无线与外设连接

| 功能 | 当前映射/约定 |
| --- | --- |
| 有线串口 | UART1，B12 MCU TX/B13 MCU RX，115200/8N1 |
| 无线串口 | UART8，D16 MCU TX→模块RX，D17 MCU RX←模块TX，115200/8N1 |
| 无线模块P1 | 1 RX、2 NC、3 TX、4 RTS/D26、5/6 GND、7 5V、8 CMD/D27 |
| 供电/逻辑 | 模块供电5V，信号0～3.3V；CMD外部上拉至3.3V，低电平进配置模式 |
| RTS | D26输入，低允许TX；前台只检查不等待，不发送AT或切换CMD |
| M1右轮 | C6=`PWM2_MODULE0_CHA_C6`，C7 DIR，前进电平1 |
| M2左轮 | C8=`PWM2_MODULE1_CHA_C8`，C9 DIR，前进电平1 |
| 舵机 | C30=`PWM4_MODULE2_CHA_C30`，50Hz |
| 蜂鸣器 | B11，启动即普通GPIO推挽低；保留GPIO银行归属修正及寄存器读回 |
| 拨码 | C26/C27低有效、内部上拉；原始高高=OBSERVE、低高=SERVO、高低=MOTOR、低低=DRIVE |
| 原有相机/安全中断 | UART4/5、CSI/VSYNC路径保留；PIT1保留10ms安全检查，PIT0不再写旧速度环输出 |

D26/27是无线模块信号，C26/27是选档输入，不能混淆。原main.h左右轮注释曾与宏冲突，
本次按实测修正注释，未交换PWM/DIR定义。C12及四键启停已停用；切档、上电或恢复配置不发车。

UART1/8各有512字节RX和8192字节TX队列；ISR每次至多32字节，前台每路每次至多16字节TX。
接收中断不解析业务、不打印、不等RTS；图像头与像素整体入队。控制权默认USB，停车x切换，
运动时拒绝接管。两端!均可停止，只有当前控制端h续租；接收错误/溢出会停止并丢弃残行。
详细协议与边界见 [DUAL_UART](../../reference/DUAL_UART.md)。累计无线errors曾为1，未定位具体类型，不宣称零误码。

## 恢复本次RAM配置

架空、停止、DRIVE档、文字模式，关闭自动发送。先x取得控制权，再逐条发送CRLF结尾的整行：

```text
x
@servo 1550 1500 1600 1
@motor_dir 1 1
@balance 1 0.667
@motor 0 0.15 0.1
@status
```

确认cap=0.15、cruise=0、scale=1/0.667、dir=1/1、servo=1550/1500/1600、sign=1。
公共150‰经整数映射得到右150‰/左100‰；这只是可用参考，不是等速证明或最低起转阈值。
cam=0和视觉ready=0不阻止本独立测试；BOARD_IO ready=1只说明拨码稳定，不能代替标定。
参数只在RAM，本次不要求@save、不确认Flash保存/重启恢复；复位后重新设置。
机器可读记录见 [motion-baseline-20261020.json](../../../profiles/motion-baseline-20261020.json)，仅为证据，不由旧恢复工具自动应用。
旧field-20261019.json的sign=-1属于此前安装，不能直接用于本次安装。

## 运动与停止操作

使用已确认的实际COM号。以下默认只预览，不打开串口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/motion_test.ps1 -Mode line -DutyPermille 150 -DurationMs 2500
powershell -NoProfile -ExecutionPolicy Bypass -File tools/motion_test.ps1 -Mode shuttle -DutyPermille 150 -DurationMs 2500
powershell -NoProfile -ExecutionPolicy Bypass -File tools/motion_test.ps1 -Mode circle -DutyPermille 150 -DurationMs 2500 -ServoUs 1500
```

要实际执行，先关闭逐飞助手对控制COM的连接，另加-Port COM10 -Role radio -Execute；
有线则按实际端口改-Port COM11 -Role usb -Execute。右圆弧ServoUs改1600。
助手维持100ms心跳，只请求一次动作；另一串口可随时!，脚本窗口Esc停止。
往复进入phase=3后，人确认机械停稳、至少2秒后在脚本窗口按R（不用回车），脚本发v；
未确认不会倒退，8秒到期reason=6。不要把未按R的结果记作倒车失败。

斜坡100‰/s，先200ms舵机预置，运动约1500ms达150‰，每段2500ms结束；
line/circle总时长约2700ms。每次结束确认机械停止，至少间隔2秒；PWM=0是撤驱动力，不是保证制动距离。
手动串口所有@行必须CRLF；h须来自同一控制端、100ms一次。500ms超时reason=3，
可能在起转前停止；另一端h不能续租。@motion_status本身停车，只在结束后查。
状态码：reason=1到时，2主动停止，3失联，4切档，5故障/互锁，6倒退确认等待超时。

## PWM保持修复与证据

DIAG_1曾在有效心跳下软件actual=150、reason=1，但用户报告实体不转。
源码中运动poll/视觉回调反复重写三路PWM，逐飞驱动每次清/设LDOK，采用整周期装载。
DIAG_2改为各路目标值改变才写，电机斜坡不重复重载50Hz舵机；停车仍强制写三路零，
使缓存失效以保证下一次同值启动重新下发。未改频率、占空比上限、相机或PIT安全条件。
用户随后确认两轮转动、限时和!停止成功，再完成落地/往复/圆弧。这个修复前后结果支持
上述原因，但没有示波器或寄存器时序记录，不能把软件actual当成实测波形。

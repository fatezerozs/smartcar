## 具体修改

1. **边缘白带不被丢弃**：已学习宽度且有当前真实单边时，模型中点可能落在图像以外。原来直接舍弃此行，现在保留当前边线和宽度，控制器重建带符号的真实模型中点，用于向仍可见的白区纠偏。只有预览用center[]裁到图像边缘；控制误差不裁掉。没有当前白像素、没有边线或没有已学习宽度时不会凭空补路。
2. **窄条不能抢先当路**：在白区候选选择前过滤完整双边窄段。中近区域y>=56至少24像素；已有成熟宽度时，完整双边宽度不得小于模型的一半。只剩单边的画面边缘白带走单边分支，不套用这项双边宽度拒绝。
3. **消除找线舵量跳变**：当前白色片段引导的找线目标改为连续的1.25倍方向目标，限制在[-1,1]。不再在绝对值0.12附近从约0.12突跳到0.60。仍以当前白区为优先；缺乏当前片段时，原有有限最近弯向搜索保留。
4. **增强弯中响应**：已经明显偏离中心（近处归一化偏差绝对值>0.35）且目标向赛道纠偏时，建立舵量的最大速率从2/s提高到3/s。普通入弯及原有限速回收机制保留。
5. **增加转向余量**：中位1550us不变，指令范围1490..1610改为1470..1630us，每侧多20us。它是指令范围，实际机械舵角尚未标定，不把它称作已经测得的转弯半径。

巡航配置保持cruise=.145、cap=.15、rise=.20/s，未提高速度。300ms短时找线期限、C26 OFF、显式STOP、断帧与编码器约束保持。没有固定先右后左或按地图时间转弯。

串口视觉行增加row90的width和flags，便于后续分辨真实双边、模型单边及显示坐标被裁边的情况。

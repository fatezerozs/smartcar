## 1. 可复现的目标轮速突降

新增同一道路的回归：两侧白色通道和中心不变，仅将双边实测行逐行改为
当前单边实测、另一边由已知宽度推算。推算边界如实标成无实测值。

C28 在 24→23 行时，目标约从 89 降到 63 counts/10ms。
C29 同一输入变为 89→86；另一镜像输入为 122→119。
两组初始稳态不同，因此这里只比较各自相邻支持量的变化，不将两组当成物理镜像速度标定。

修改包括：

- 双边支持在 8–24 行间连续增加；完整、非 partial 的当前白色桥接可以提供完整支持。
- 单边支持按数量、连续长度及近远区域覆盖连续计算。
- 输出层在 base=50、edge=92 和现有 paired/corner=132/104 标度间混合。
  `speed_boost` 留作诊断标签，不再直接选择轮速尺度。
- 直道增益也按双边支持连续变化，避免 24 行门槛同时撤销直道需求。
- 所有循迹目标使用共同上升包络，保留当前差速比例；减速和保护停车仍立即生效。

这不是继续提高最高目标，也没有重新引入固定 40% PWM 上限。
提高实际平均速度的预期来自减少无依据降档，需要实车计时确认。

## 2. 当前白色余量内的相切入口

原来的固定 `0.18 × width` 偏移既可能用不满宽入口，也可能因末端一个暗像素而
放弃整行引导。现在候选偏移上限为 `0.35 × width × progress`，从当前道路中心
向暗岛同侧逐像素推进，遇到暗像素或视野边缘即停止。

`progress` 仍来自当前暗岛下端在图像中的位置，不是行驶时长。
候选两侧各保留约四分之一道路宽度；原始中心到候选的连接必须全白；
至少 12 行有效引导才发布。没有当前暗岛就没有入口引导。
实测边界、道路宽度学习及 raw_error 不受引导偏移污染。

相同的合成入环控制链路，旧版左右峰值转向约 0.708/0.738，新版为 1.000/1.000，
命令仍受实测舵机 1430/1550/1670µs 端点及转向速率约束。
这只说明增加了可用入口转向需求；较强转向的实际轨迹和速度需试车验证。

## 3. 贝叶斯如何参与

调度器在每帧前通过 `tb_route_hint` 读取上一帧尚未过期的已接受结果。
只有 configured、trained、accepted、have_frame 和时间有效均满足，且状态为
`RING_L_ENTRY` / `RING_R_ENTRY` 时才产生 -1 / +1 提示；其他情况为 0。

该提示仅将同侧、当前可见侧裁剪暗岛的确认从 5 次降为 3 次。
每次仍需当前独立暗岛几何检测成功；异侧、未知、失效、普通道路不会得到额外票数。
提示一帧消费一次，OFF、复位、低对比和新观测均不保留旧提示。
它不生成边界、不跳过绕行阶段、不覆盖道路方向，也不以模型概率直接调 PWM。

已有训练入口 `tools/fit_track_model.py`、`VISION_BAYES_FITTED_MODEL` 保留。
仓库没有可用的真实人工标注训练集，本次不伪造 trained 参数；默认模型仍不发出导航提示。
生成与启用实车训练模型见 [贝叶斯说明](../history/BAYES_REFACTOR.md)。

## 4. 卡顿定位与串口记录

C26 运行时每 100ms 最多一条整数 `[RUN]`，替代原 RUN/SPEED/TURN 三行浮点输出。
仍走有界非阻塞队列，停车后的 TRACE 导出协议保持不变。

- `target` / `measured`：右/左轮 counts/10ms；`pwm`：实际下发右/左占空比千分值。
- `duty`：视觉控制需求，不能当作实际 PWM；`e/h/u/duty/paired/edge` 按 `scale=1000` 读取。
- `process_max`：自上一条运行记录以来，相机复制后算法与贝叶斯处理的最大耗时（ms）。
- `gap_max`：该窗口内处理帧起始时间的最大间隔（ms）；`age/enc_age` 为帧/编码器样本年龄。
- `ring/side/guide`：同帧圆环阶段、方向、入口引导行数。
- `bayes/accepted`：模型候选枚举和是否接受；候选不是已确认状态。
- `enabled/faults`：编码器速度环是否使能及当前控制/编码器故障位。
- `pwm_hz_cfg=17000`：初始化请求的电机载波配置，必须另用示波器核对真实波形。

目标先下降时检查路径支持/控制需求；目标稳定而反馈下降时检查实际 PWM、供电与负载；
处理/帧间隔明显增大时检查相机与主循环。文字遥测为 10Hz，无法排除更短的瞬态。
`analyze_training_run.py` 和 `import_seekfree_log.py` 同时支持旧浮点三行格式与新整数单行格式，
统计时按 scale 还原误差单位，并从新 RUN 提取真实轮速/PWM；原始日志字段保持原样。

# C31：相切入口引导连续性检查与修正

日期：2026-10-22。保留 C29/C30 改动，版本 `MIDTERM_C26_31`。
操作者反馈：C30 仍基本沿直道通过，转向不明显。本次没有新增车端运行日志，不能将主机复现直接认定为该次实车的唯一原因。

## 现有逻辑的缺口

`reference_roundabout_island()` 原来用 `border & 12` 拒绝触碰 ROI 上端或下端的暗块。
`reference_roundabout_observe()` 每帧先清空 `island_visible`，只在重新找到满足完整条件的内岛后恢复。
`reference_ring_entry_guide()` 则要求 ENTER 且 `island_visible != 0`。

因此，一个已经可靠确认的内岛，其下端接近并离开 ROI 时，状态仍可能是 ENTER，
但入口引导突然变成零；实际道路边界仍然存在，控制器便又按原先的直道中心驾驶。
这发生在最接近切入的位置，不能用“之前某帧出现过 ring=1 / guide>0”证明入环动作完整。
C30 的实拍测试修正了部分漏检，却遗漏了这个动态视野截断条件。

## 主机复现

使用已有相切地图的灰度投影，先在直路建立相机宽度，再逐步改变固定车头方向的观察位置。
主机跟踪采用开关工程的实际轴线、near=.86/far=.62、kp=1.20/heading_gain=1.20、连续运行配置。
新回归同时通过实际 `vision_drive`、轮速输出适配和舵机 PWM 桩检查，不只看视觉状态。

| 投影观察位置 cy | C30 当前内岛证据 / 引导行 | C31 当前内岛证据 / 引导行 |
| --- | --- | --- |
| 410 | 完整 / 87 | 完整 / 87 |
| 400 | 无 / 0 | 同侧下端截断 / 87 |
| 390 | 无 / 0 | 同侧下端截断 / 87 |

cy 是合成地图的观察位置参数，不是实车距离、时间、车速或闭环轨迹。
该投影固定车头且不响应转向，不能据此声称完成了真实入环。
原 C30 在新增的实际控制链路截断连续性断言上失败，C31 通过。

另外，C30 的独立实拍控制模块测试使用了默认观测控制器参数；
C31 已将该测试配置改为当前 switch 工程的轴线、增益、采样带及连续运行参数。
此前 C30 对照图可用于识别差异，不应把其中模拟转向数值当作实际车端转向。

## 修正条件

新入口仍要求原来的完整/侧边截断内岛证据和确认票数，不能仅凭底部暗块进入环岛。
只有已经处于 ENTER，且先前内岛下端已到 ROI 底部附近时，才允许延续：

- 当前仍有同侧暗块、可见上端，且上端位置与上一轮匹配相近；不跨侧切换到另一内岛。
- 至少 10 个当前支持行、8 个与当前道路边界吻合的行，并有足够纵向跨度。
- 当前白色通道宽度和外侧直线拟合仍通过原有最大偏差及 RMS 检查。
- 下端被截断后，剩余轮廓允许比新识别少两个粗采样列；面积、宽高比、当前连接和纵向支持仍受约束，避免镜像采样差一个列导致断续。
- 当前像素不再支持这些条件时，不延用历史像素或固定转向；原有当前白色余量验证继续约束每一个引导点。

C26 启停、速度参数、PI 参数、转向增益和舵机端点均未修改。
这次不是靠增大舵机幅度或预设左/右转时长补偿。

## 回归

- 反例：仅底部截断图不能新建入口；远处内岛不能突然接到近处暗块；空白帧不保持旧引导；OFF 撤销。
- 双向投影：连续接近 ROI 下端并跨过截断位置，检查当前证据与引导不断；保留原有弯道、十字及出环阶段回归。
- 完整控制链路：检查截断阶段仍为本地运行、保持入环方向转向及当前引导，而非只统计转向峰值。
- 实拍子集：按实际 switch 配置回放，保留图像镜像、白色余量和曲外边界反例。
- 正常回归、内存检查及 Keil 构建结果见发布目录 `release.json`。

## 新增诊断

文字模式自动 `[RUN]`、停车后的 `[VISION2]` 增加：

| 字段 | 意义 |
| --- | --- |
| `ring` | 0 空闲、1 进入、2 跟随、3 退出、4 冷却 |
| `ring_seen` | 0 本帧未获得完整/延续内岛证据、1 当前完整条件、2 已匹配的下端截断延续 |
| `ring_candidate` / `ring_votes` | 空闲阶段当前候选方向及确认票数；进入后不作为新的分类结果 |
| `guide` | 当前入口引导行数，0 表示未生成入口引导 |
| `u` | 实际控制器转向输出，`scale=1000`；正为车体右转，负为车体左转，不能直接等同赛道平面图左右 |

FOLLOW 阶段依赖当前道路/内边界，不再要求重新看到完整暗岛，因此 `ring=2, ring_seen=0` 本身不是故障。
实车若仍沿直道通过，应被动保留入口前后的 `[RUN]` 行，分清没有识别入口、引导丢失或输出已转向三类情况。
无需发送 `@status` 或切换图像模式；它们会改变运行状态，图像采集也不是运动中的同步录像。

1. 从 B 朝图左，沿底部长直道行驶。

## 控制修改

- 直道巡航 .145、PWM 上限 .15、内侧轮随舵量减速、渐进舵机映射保持。
- 有效观察且近端居中、远端预瞄可用、当前双边实测行充分时，将弯道最低基础需求从巡航的 45% 连续抬升，最多到 55%。最大提升约 22.2%，指速度目标，不能承诺实际车速同比增加。
- 提升量随覆盖率、居中程度、实测行数量连续变化；缺少远端或只有模型行时不增加最低档；大偏离也维持原最低档与原前进降额。
- 用“当前转向目标”和“已输出的转向命令”共同计算速度上限。紧弯入口立即压低速度目标，不等舵机指令逐渐到位才减速。
- B→A 的连续反向弯中，近远路段方向相反或旧转向尚未回到新方向时，降低提速量，避免指令过中位被当成长直道加速。加速仍受 .20/s 限制。
- 无当前赛道、帧超时、编码器异常、C26 OFF、运行时限等原有逻辑保留；短时找线仍限 300ms，未延长盲走时间。

# 2026-11-12 NEWNEW C26 V11 提速与实车交接

## 背景

基于 main 提交 1db7885 的独立 NEWNEW V10。操作者报告 V10 可以正常行驶。本轮将直道速度请求从 1.4 提至 1.5 m/s，用于实车对照。

## 文件改动

| 文件 | 变化 |
| --- | --- |
| demo/user/inc/drive_tuning.h | TARGET_SPEED_MPS 从 1.4f 改为 1.5f |
| demo/user/src/main.c | UART8 遥测标识改为 NEWNEW_C26_V11 |
| tests/test_tuning.c | 更新左右编码器目标为 170.910 / 170.835 计数每 10 ms |
| tests/test_swing_brick.c | 更新巡航目标和直道请求断言 |

弯道沿用原插值公式，轻中度转向的速度请求随巡航目标变化，大舵量限值仍为 0.9 m/s。环岛和避砖的上限分别为 1.0 和 0.55 m/s，C26 仍负责启停。

## 验证与待办

- V10 和 V11 均通过 GCC 调参及转向避砖专项。调参日志含 4000 次边界、速率和抖动检查，避砖专项 failures=0。
- 本机 Keil 重编两版均为 0 错误、2 条相同的 SDK 浮点警告。
- 操作者报告早期 V11 试车时前轮摆动，车未前进。同场烧回 V10 后确认能跑。V11 再次写入曾遇到 DAP 连接错误，主板断电重启后写入校验通过。校验后仍出现 RDDI-DAP Error，此次重烧后的运行遥测及试车结果待补。
- 1.5 m/s 是软件请求。实际轮速、起步表现和完整赛道成绩待测。排查时记录 C26、斑马线状态、避障阻塞、速度目标和实测轮速。

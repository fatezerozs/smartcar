# C0 不确定度与留存要求

不确定度不填假常数。每类数据保留全部原始值、仪器分辨率、重复条件、左右轮及接近方向，先检查滑移/回差/测点差异，不直接平均掉系统偏差。

同条件n次读数：均值xbar，样本标准差s；重复性标准不确定度u_A=s/sqrt(n)。若读数分辨率q可按均匀量化估计，则u_B=q/sqrt(12)，前提必须写明；有校准证书时按证书分布和覆盖因子换算。独立项合成u_c=sqrt(sum(u_i^2))，相关量需保留协方差；没有独立性证据不强行RSS。报告扩展不确定度U=k*u_c时写明k、近似覆盖解释和样本限制，不把n=3称高置信长期范围。

周长C=D/N，若N为可靠整圈且无滑移，可传播距离与圈数误差；否则圈数和滑移同样计入。CPR=sum(delta_counts)/wheel_turns，16位回绕不明确的数据不能给出CPR结果。后续速度v=delta_counts/CPR*C/dt的误差同时包括计数、CPR、周长及dt；缺一项时结果 unavailable，不以0代替。

舵机曲线分别保留左右前轮、从左/从右接近的关系、死区和滞回；局部拟合/插值只是provisional，不能越过安全测量区外推。轴距/轮距测量点选取误差独立记录。空载/负载、不同胎压/地面分组，不能混为单一常数。

本轮所有物理值UNKNOWN；C0_PARAMETER_REVIEW.json中的value/uncertainty=null。没有真实曲线、置信区间、动态制动或far-loss参数。本车物理标定与留出Session验证留在C1/D相应阶段，不写生产配置。

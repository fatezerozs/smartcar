# C0 静态本车标定规程（仅准备）

本轮未量测、未通电或执行舵机/电机动作，不写midterm_route_profile.h等生产参数。原始表见C0_MEASUREMENT_TEMPLATE.csv：84条unknown记录、31列，数值观测保持空白。日期/操作者/照片/环境随每条测量填写，不以示例值占位。

## 机械几何

车辆断电并安全固定，由人工确认允许测量后，明确前后轮接地中心/转轴中心测量点，测轴距；后轮轮距取左右轮接地中心。每项至少3次，重定位量具后重复；单位mm。照片标记测量点、仪器与读数。不得用车架外沿距离代替轮中心距离。
左右轮负载条件下做轮胎标记，人工低速直线滚动完整若干圈，记录总距离roll_distance_mm和wheel_turns，周长=距离/圈数。避免滑移、转向和反向回差；记录左右、载荷、地面、胎压（可测时）、温度，空载与负载分开。不得以电机驱动车辆完成“静态”测量。

## Encoder counts/轮

先确认传感器位置（电机侧/轮端）、硬件模式、线束、轮方向。当前源码保留A上升沿/B方向，不按“1024”标签或四倍频估算轮端CPR。
计数读取需要传感器/逻辑电源与只读接口，须另行批准；电机驱动电源隔离。人工分别转左右轮前/后向完整圈数，记录原始before/after、实际圈数和方向。默认表counter_bits=16来自当前接口类型，并非实测CPR。
16位模差仅在每段真实变化绝对值<32768时无歧义。CPR未知时使用小角度分段/高频只读累计，不先转多圈再猜回绕次数。将每段有符号delta累加再除以实际轮圈数。测方向符号不等于授权改变生产sign参数。

## 舵机命令—实际转角

仅编写规程，本轮不下发PWM。另行批准前，确认电机断电、转向机构可自由运动、机械限位、舵机允许脉宽/频率和紧急断电方法；未知时不猜1500us为安全中心。
经批准后先验证安全中位，再以小步逼近左右安全边界，覆盖左/左中/中/右中/右五个位置，从左右两个方向接近各点，各至少3次。分别测量左前轮与右前轮角度，不能把二者当同一转角。记录command_us、实际angle_deg、approach_direction、command_position、重复值、死区和滞回，附量具/照片。
命令脉宽是控制输入，实际角度是测量值；两者分列。机械保护优先，出现顶死/异响/电流异常立即停止，由人工断电，不通过扩大软件命令范围“找极限”。

## 状态与审查

unknown=缺测；provisional=已有原始记录但误差/适用条件或审核未完成；measured=测量流程与不确定度齐备，不等于获准生产使用。参数发布另需calibration_version、原始记录sha、环境适用范围与审核人，批准前production_approved=false。

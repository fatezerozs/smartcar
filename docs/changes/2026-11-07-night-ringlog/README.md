## RINGLOG3 已完成的代码变化
1. 发现 RINGLOG2 路宽模型第90行始终75像素，而真实画面道路约124像素；各行模型从不同开机姿态分散学习后冻结，出现不一致。增加普通道路下连续8个新帧、真实双边界、透视宽度与中心线一致性检查，仅更新有实测支持的行。没有增加发车等待或清空有效模型。
2. 撤回 RINGLOG2 未取得出环资格时的岛侧优先搜索，恢复 RINGLOG1 的前方优先选择。
3. 仅在已确认 EXIT 且当前出口补线与真实锚点足够时，让当前出口预瞄决定方向，反向近端误差只能削弱，不能抵消出口转向。保持普通循迹、入环控制分支和机械限幅。
4. 保留 C26、发车逻辑、电机闭环、速度参数、原始入口生成器、SD 核心。调试器导出增加逐行路宽表。

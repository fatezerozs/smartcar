## 生产集成前必须关闭的设计差距

- 规定near-valid几何定义；当前route单边建模/partial与新任务的near-invalid零驱动边界不能含糊。
- 明确C26视觉故障OFF→ON重新准入的故障分类；当前源码ON可恢复与v1.4目标存在差异，不能沿用旧测试便称通过。
- 保留严重encoder/config/actuator/control故障，不允许OBSERVE/OFF一概清除；人工STOP仍按operator抑制和物理开关解除。
- 收缩主构型准备/PI/启动外围PRIMASK，构建一致快照/请求版本/最终generation复核；此轮只审计，未改生产区间。
- near-invalid必须在最终motor writer和PI缓存处封口，far-only非零模型不能被AUTO_TRACK零抑制误覆盖；两者在实际主构型专项测。
- 若采用几何分配，关闭旧未经标定经验steering_mix的并行作用，避免重复分配；修改必须和真实标定一起审查。
- Recorder遥测只可在独立训练构型，使用已有RTOS队列/单Storage所有权，不将同步文件写/flush插入主线控制。

上述门不因Host测试或Keil构建通过而自动关闭。本轮未编造标定日期、数据集版本、测量误差区间、真实速度跟踪曲线或物理安全结论。

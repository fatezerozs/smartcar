## 申请范围

1. 用户提供准确串口，确认当前目标固件身份，并确认无人同时使用该串口。
2. 用户确认C26 OFF、C27 OFF、两驱动电机电源物理隔离，保留MCU/编码器逻辑电源；车体固定，可由人缓慢手转车轮。**不使用新的规划原型发车。**
3. 先被动读取串口文本核对版本；若固件不是已知MIDTERM_C26_31或支持现有诊断协议的版本，终止，不自动刷机/重启/尝试未知命令。
4. 在身份和用户就绪确认后，仅执行既有工具的停机、取得串口所有权、切文字模式及 `@encoder_hw` / `@encoder_status` / `@status` 状态读取。
5. 每次取得before后由用户手转指定车轮，再取得after；先左、再右，正反向分别记录，每轮每方向至少3个独立重复。禁止自动使电机带轮转动。

既有 `tools/field_serial.ps1` **不是纯被动只读工具**：带Command参数会发送 `!s` 停止、`x` 取得所有权、`?t` 帮助/文字模式，以及最后 `@status`。`@encoder_status` 本身也会停机。申请包含这些明确协议写入，不把它们描述成“零写入”。

不申请：`a`/`h`启动或维持运动、`@motion`、`@wheel`、`@probe`、速度/方向/舵机配置、`@save`、自动清故障、持续SD采集、RESET、下载/烧录。当前Host/ARM对象没有可直接烧录的完整实验固件；若后续需要烧录，必须另列具体AXF/BIN哈希、构型和测试步骤再申请。

## lower01的人工总行程核对

用户原文：“从开始到结束总410mm左右，误差5mm以内”。这是整段路程，误差为操作者估计，不是独立检定的±5mm。连续记录换算的整段轮端路程左347.53mm、右346.17mm，共同平均346.85mm，比人工410mm少约63.15mm（约15.4%）。人工距离/轮端距离约1.182，仅描述本次差异，不把该倍率直接乘回生产周长或CPR。

本次位移差异与video03的估算不构成同一恒定修正：video03人工停车段约300mm、轮端约361mm，而本次整段人工410mm、轮端约347mm，量测窗口和参照不相同。鸣声时刻、量尺读数、轮端转换、滑移/计数及试验条件均需分别核对。不能把一个事件的偏差用另一个反向偏差抵消。

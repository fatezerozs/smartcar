## 本轮记录

沿用已试过的200‰、3000ms、1550µs中位、配平1/1、开环及COM10无线。新候选首次允许200‰，硬上限仍200‰；心跳、拨码、STOP及3000ms上限保留。当前只测撤去驱动后的滑行停车，不施加反向动力。

在10ms编码器采样处记录时间、采样序号、原始归一化10ms计数、累计计数、软件提交PWM和动作状态。容量640条，软件零输出后继续记录2000ms。累计量用于路程换算，不以抽样速度积分冒充完整路程。冻结后禁止新动作，按记录代号导出、CRC核对并明确释放后才可再次启动。若尾部仍有运动计数，停车过程按未完整覆盖处理，不宣称已停稳。

蜂鸣器200ms标志由停止后的安全tick发起，表示软件撤输出事件。它有调度、发声及声传播延迟；不代表示波器测到的PWM撤销，更不代表机械瞬停。视频正常60fps并保留音轨；每帧约16.67ms只是名义采样间隔，不是完整时序准确度。

## 执行步骤

1. 电机断电、两拨码OFF，接下载器。换烧后明确报告版本和Verify结果；复位后一次性初始化配置。
2. 静止测试蜂鸣器标志，先确认手机录音能清楚收音。无清晰音频标志则不把视频时间直接对齐到撤输出。
3. 手机固定侧拍，镜头覆盖起点、运动段及停车位置；地面摆放固定刻度、避免透视遮挡，保留后轴中心可追踪参照。录制至少运动前2秒，停止提示后继续至少3秒。
4. 车辆回起点，前方保留3m余量，动力开启、DRIVE且人员量具离开后，操作者报告就绪；单次200‰/3000ms。明显偏航立即断电，原记录照实保留。
5. 操作者确认机械停稳后导出冻结记录，主控不得断电或复位。导出为只读查询，禁止在运动过程中调用；导出本身会发送STOP，并拒绝未冻结/溢出/不完整记录。每行原始字节保留，独立CRC32及时间/序号连续性检查通过后生成trace.json。
6. 保存手机原始视频及实际前移/横移测量，再核对音频标志、轮端累计路程与物理位移。先报告误差及是否完整停稳，后讨论减速度/停车预算；单次不生成生产安全参数。

## 先取得什么

先测小转角、低速短弧的实际方向、后轴轨迹、朝向变化及左右轮计数。它补充车辆运动几何，不是侧向附着极限试验，不从一次正常转弯批准a_lat_max。首先左偏1600µs；已有左轮角tanδ=-0.1785的历史测量，但1600µs复测有滞回/重复差异，因此不是固定实车转角保证。右偏1500µs只有用户授权镜像参考，必须另行观察，不标记为已实测。

开环短弧使用左右相同的受限努力请求，允许轮端自然出现速度差；不把左右相同闭环计数目标用于短弧，以免速度控制抵抗转弯所需的差速。开环响应受电压、负载影响，不能保证对应车速，因此保留编码器速度保护及现场断电能力。

## 现场操作与测量

1. 保持电机动力断开、C26/C27均OFF，接好下载器；换烧后明确报告版本、Programming/Verify及运行身份，再恢复RAM和quiet1。新固件默认不启动，RAM不可沿用旧会话。
2. 独立确认架空固定、动力和清场后，仅执行首个1600µs/200‰/1000ms点，核对实际左转、轮端方向/异常及停稳，完整导出。不是重复已有直线架空测试。
3. 落地时在足够宽的空地标后轴中心A和初始车身中心线。胶带标尺置于车外，不进入轮下；选固定俯视/高位60fps视频，尽量让地面标尺、车身前后中心和整段轨迹入镜，保留声音以辅助对齐结束短鸣。先提供现场就绪，再单发同条件短弧，观察偏向不符或异常立即断电。
4. 停稳后测后轴中心相对A的前移x、横移y（右正左负），并用车身前后两点确定最终朝向；提供量尺误差、地面、载荷/供电改变和滑移观察。最终位置包括滑行，先作为全动作结果保存，不能直接代替带动力曲率。
5. 若有视频和可辨识地面参照，在带动力、轮角稳定的片段选至少3个后轴中心点拟合圆/检查残差，同时比较朝向变化。相机透视需地面映射或近似俯视及误差说明；短弧近共线时半径估计病态，不硬给精确R。

理想恒曲率、以起始车身前向为x且横向右为正时，端点估算`R_signed=(x²+y²)/(2y)`、`Δψ=2 atan2(y,x)`，仅当转角稳定且区间符合圆弧时可用；`y≈0`不能据此给可靠R。若x/y是毫米，R也为毫米。后轴左右轮计数可按候选尺度和后轮距152.9mm作无侧滑轮式里程对照，但不是独立地面真值，不以轮式估计验证自身。

后续左右比较、不同低速和实际侧滑/抓地边界需另外场次；未测的右偏镜像、曲率、侧向加速度均保持未批准。不把这一准备任务替代Phase2剩余动态视觉预算或MPC端到端时延。

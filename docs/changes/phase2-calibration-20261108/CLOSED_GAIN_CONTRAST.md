## 如何执行与比较

先确认可靠架空、停稳、动力开启、手和线缆移开，主控保持供电。若复位则按首点门槛恢复，不能跳过200‰。仍只执行一条动作，不自动扫参。

客户端新增`--kp/--ki`参数，默认仍为2/0.1。动作前检查参数有限值与固件范围，再设置RAM，回读实际Q8对应的十进制增益、目标和启用模式；不一致则在运动命令前退出。下一条记录的10字段配置和22字段轨迹仍共同覆盖CRC。框架未改变固件保护或原始数据。

仅打印计划，默认不连接串口：

```powershell
python -m tools.speed_planning.run_speed_response `
  --request 250 --duration 3000 --mode closed --target-ticks 23 --kp 2 --ki 0.05
```

现场就绪后，在上述参数上增加COM14、唯一输出目录、`--execute --bench-ready`及`--release-verified <基线完整trace.json>`。旧缓存先核对generation/count/CRC再显式释放。无需重新烧录，未复位时无需重做整套RAM硬件配置。

比较必须先核对冻结配置，确认只有kiQ8改变。保留正常到时、故障或提前退出的全部结果；按control_seq对齐原始反馈并排除已知目标0残值。比较起步时间、完整目标段、末300/500ms和更长后段的反馈范围/RMSE、输出饱和及累计计数。若候选尚未完成起步，不把同样末窗误差直接解释为稳态性能变差或变好；不得丢弃异常轮次。

本轮没有确定稳定性阈值、最优增益或生产批准。架空单次对照也不能取代落地负载与实际电池电压记录，450档车速及600‰物理输出能力仍未验证。

## 待做清单：推进有效运动影子验证

2026-11-09按讨论明确以下必要步骤，按依赖顺序推进。勾选表示对应证据已归档；本次只登记任务，不代表已执行、烧录或取得动力接管验收。

- [ ] **1. 定位并修复板端真实路径输入断点。** 导出同一帧188×120完整灰度、阈值、边界、帧号及采集/处理时间，复现V4缺54/52行的问题并加入原图回归。验收看正常无遮挡场景能否稳定提供可信路径，并保留失败原因；不以单纯放宽准入提高通过率，不把94×60放大预览当成同帧原图。
- [ ] **2. 准备一致的影子固件与配置。** 明确本次源码、配置及构建身份，完成对应软件回归与ARM构建，上板后核对实际身份。确认SHADOW、主动控制关闭、原PI仍掌握动力；最新near/full解耦尚未烧录，必须区分源码与板载版本。
- [ ] **3. 停机确认真实输入和记录可用。** 核对路径、采集时间、编码器方向与尺度、历史里程对齐及配置版本；确认停机后可以导出影子记录。无需每帧都有效，但必须能区分识别失败、时间对齐失败与规划拒绝，记录能对应本次固件、配置和运行。
- [ ] **4. 完成一次短距离、低速运动影子验证。** 原控制负责行驶，新规划器只计算。停机后对照规划目标、实际轮速、路径有效距离、拒绝原因和计算耗时，检查目标合理性与连续性，以及并行计算对原控制时序的影响。现有查询会先STOP，不在运行中轮询这些查询；归档结果和剩余问题后再决定后续主动接管步骤。

**不作为首次影子验证的前置阻塞：** 完整连续降级控制器、最终制动/jerk/侧向能力/恢复期限、完整环岛回归、全部开源候选比较及完整SD录像系统。影子计算可使用明确标注的实验参考值，不将其当作生产参数或实车依据；已有尺度、响应和停车资料继续利用，不重做整个Phase2。

**后续待办仍保留：** 根据影子运动证据完善可变路径段、残差权重、有效视野与能力约束、连续恢复，以及每次行驶独立追溯；再核定主动接管所需参数并进行受限闭环验收。动力、惩罚与恢复在不影响功能需求的前提下保持连续化，相关拒绝不重复扣减，普通识别波动不单独升级为终止运行。当前恢复期限按方案保留，不凭静止帧选定生产停车/恢复参数。

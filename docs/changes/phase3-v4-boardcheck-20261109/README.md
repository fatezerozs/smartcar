![当前V4板端叠加图](evidence/static/o-0.gray.png)

原图预览为94×60、从188×120每隔一像素抽样。顺序采集的三种模式不是同一曝光，协议只有固定帧头/长度，没有像素CRC或帧号。对这两张灰度预览做明确标记的2×2复制诊断，模型却得到近/完整有效，与板端丢行不同；复制不能还原被抽样丢弃的像素或原状态。因此不使用该模型结果宣称板端通过，也不依据它调整识别参数或放宽采样域。

下一步需要停机回读**同一帧188×120完整灰度及对应原生行/阈值状态**，将当前断点加入原图回归，再修复识别或采样处理。当前不安排ON影子动作；缺少几何时再做一次动力隔离ON只会重复输入未准入/无轮速反馈，无法关闭该问题。后续可信几何可用后，再独立验证ON规划、原PI并行与实际反馈。

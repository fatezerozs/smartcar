## 2. 连续化的统一实现原则

**证据减少时降低可用能力，证据恢复时平滑恢复能力；拒绝一个候选不等于终止一次运行。**

1. 正常直线、弯道和元素处理始终是主任务。降级逻辑在证据变差时介入，不能让日常运行长期处于低速异常模式。只做有依据的性能限制，不堆叠任意超时、概率或限速门槛。
2. 可靠性不压缩成一个“总分”。保留空间覆盖、实测/推导来源、残差、时效、标定适用性与方向歧义；这些量连续参与路径、预瞄、速度和加速约束。coverage不是概率。
3. near/far逐步过渡为带有有效距离和误差的路径段；旧布尔字段仅作兼容视图，不能成为全部控制信息的唯一来源。过渡期间不伪造旧字段语义。
4. 目标速度、加减速、转向和恢复权重应连续或受斜率/jerk限制。双PI目标连续不代表PWM或实车速度已经平滑；需观察饱和、积分、死区、实际轮速和跟踪误差。已有唯一writer与PI所有权保持。
5. 同一原因的多种报告不重复处罚。把缺行、出域、near/full失效等视为证据/约束输入，避免每层都乘一个降速比例导致动力塌陷。相关上限由一个位置统一合成并整形；若以后使用优化代价，归一化与权重来源必须明确。
6. 恢复也连续：新鲜、连续证据逐步补回权重/预瞄/加速能力；允许合理恢复，不因单帧恢复立刻满速，也不因单帧再次抖动重置全部历史或积累永久处罚。

当前工程包含监督、空间限速与jerk整形，不应将本文连续代价设计表述为已实现完整预测优化器。方案可以先通过适配层和现有规划接口表达，再逐步统一契约。

## 3. 软处置应怎样工作

### 远场变差，近处当前路径仍可靠

先减少远端对转向和速度规划的影响，禁止依据未观测路段继续加速，随可靠视野逐步缩短而降低速度上限；不直接把PWM清零或撤销运行授权。已有可靠路径不因一次新候选失败立即作废，但必须扣除实际行驶及姿态变化，不能反复续用旧路段。

far缺失的时间与路程用于更新可用视野和不确定度，不宜单独以任意固定期限作为终止惩罚。只有这些证据说明继续行驶已无法满足跟踪/停机边界时，才将目标连续收敛到停止。当前实现里的既有期限在实现审查前保持原样，本文不视为已移除600ms或任何生产约束。

### 某些near样本缺失，但仍有可靠当前近场引导

优先利用同帧其他真实边界和已验证单边几何，降低速度/加速、限制不确定路径的影响；采样数量可变并保留缺口，拟合结果标注为推导。路口/环岛路径按拓扑与来源单独处理，不为满足旧“双边中点”契约强行拉回道路中点。

控制应有明确的可用近场证据门槛；不会因用户偏好软处置就把不明方向当作可走方向。阈值和连续代价的具体数值暂不填写，需用完整序列与实车跟踪表现确定。

### 近场没有可靠方向，但尚有有界的有效运行上下文

停止增加动力，优先受限减速；如果连受控路径跟踪也无法成立，采用零驱动短暂恢复等待。零驱动是当前输出选择，不自动等于锁存故障或终止会话。保留有限的当前转向/运动证据，不长期盲目保持转向或假装车辆仍沿直线。允许在原授权与有效恢复条件内平滑恢复。

等待不无限续期；根据实际运动、残余可靠视野、误差及可停止性决定还能否等待。没有本车时延/停车依据前不发明新的固定恢复期限，也不宣称目前300ms/5帧等参考已经经过物理验证。

### 不再具备继续行驶依据

目标优先通过可行的减速/jerk路径降到零，并用不同反馈样本确认停稳。这是有原因的受控停止，区别于单帧拒绝后立刻故障锁死。停止过程仍应保留剩余可靠方向引导；不能为追求曲线平滑超出已知可停边界。停稳后按既有授权规则处理；普通新图像不自行重建被撤销的启动权。

## 4. 必须保留的硬边界

连续化适用于有意义、有界的候选与可行控制区间，不把任何未知情况都当作可继续行驶。

- 显式STOP、物理OFF/撤权：立即按原优先级撤输出，不用平滑延迟违背操作意图。
- 输出失控、危险数值将进入最终writer、关键执行/反馈链确实失效等无法保证有界控制的情况：拒绝危险候选并执行必要停止。坏候选若可被隔离，优先拒绝该候选，不把每次隔离都升级为会话锁停。
- 缺失路径或可信运动证据发展到无法在有效视野内满足可停/可控要求：不能继续盲行；能受控就受控停止，无法受控才采用必要的直接撤输出。

识别缺一行、far一帧无效、映射轻微出域、候选残差偏大，均**不单独构成上述硬停止条件**。NaN/单位混淆也不能通过加低权重继续进入计算；硬数据校验与整车终止是不同层级。

## 5. 适配层落地边界

适配层先输出有来源的边界、路径段、误差/质量量和拒绝原因；目标形成、约束合成与恢复由单一控制所有者处理。运行中不能自动换参数源、切换另一套PI或创建第二个writer。若增加像素路径的降级使用，必须是明确设计并验证的同一控制链路，不是临时绕过米制入口、擅自回退到旧控制模式。

影子模式只记录上述指标与建议，不改变现有动力或启动授权。候选算法的越界读取必须修正/隔离后才能评估上板，不能用软惩罚弥补内存访问错误。

## 6. 下一轮验证要证明什么

- 同一输入序列下，分别报告候选拒绝率、实际路径可用距离、降速幅度、参考加速度/jerk、转向变化和恢复过程；不要用单一PASS或停止次数概括。
- 无遮挡直线、正常弯道、环岛进出和遮挡/反光分开统计；评估误停、频繁减速、反复恢复及有效跟踪，不通过持续低速掩盖功能失败。
- 离线检查权重/约束的连续变化、相关原因不重复扣减、旧帧不续命、恢复不跳变、未知方向不继续加速，以及STOP/撤权优先；速度与停车物理能力仍须实车验证。
- 当前750帧均为静止输入，缺少同步真实运动和完整环岛序列，不能从它直接选出生产速度、惩罚权重、停止距离、恢复期限或宣称安全/性能通过。

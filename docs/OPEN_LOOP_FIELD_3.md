# 中期电机开环现场版 FIELD_3

此页为 FIELD_3 历史说明；当前 FIELD_4 的 C12 本地启动与持久化改变了复位行为，最新规则以 [C12_STARTUP](C12_STARTUP.md) 为准。

2026-10-19：按用户要求暂停额外现场检查，直接迭代代码。此轮仅离线测试和编译，没有连接 COM9、启动执行器或烧录。板上此前已确认运行的是 FIELD_2；不要把磁盘上的 FIELD_3 当作已安装版本。

## 控制方式

电机完全采用开环 PWM，不初始化、不读取编码器，也不执行旧速度 PID。摄像头仍闭环控制舵机：近处归一化横向偏差 + 滤波微分 + 远处方向差，随后经过转向限幅和变化率限制。不是定时转弯、固定路线回放，也不是视觉测车速。

公共电机占空比按以下关系逐帧生成：

`target = cruise × coverage / (1 + lateral_weight×|e| + heading_weight×|h| + steering_weight×|u|)`

远带缺失时再乘 missing_far_scale；目标不得超过 cap，增长不得超过 rise×dt，降额立即生效。coverage 是有效行覆盖分数，不是模型正确率。近带无效或视觉不可靠时直接停车，不用旧帧硬撑。

FIELD_3 在最终硬件输出前增加两路独立衰减：

`motor1_pwm = base_pwm × scale1`，`motor2_pwm = base_pwm × scale2`。

scale 默认 1/1，只允许 0～1；不提高一侧来绕过总 PWM 上限。任一侧为零允许保存但不能解锁行驶。改比例立即停车、撤销旧帧的解锁资格；非法/非有限数值整行拒绝。不自动猜哪边是左轮，不自动学习电机不平衡。

这不是转速闭环：相同 PWM 不保证相同轮速，电池电量、轮胎、摩擦和负载都会影响结果。没有电流/转速传感器时不能可靠检测堵转、打滑或欠压；软件租约不能代替物理急停和操作者监护。

## 工程位置与模块

仍使用本项目 `demo/mdk/rt1064.uvprojx`，目标 `nor_sdram_zf_dtcm`，输出 `demo/mdk/Objects/rt1064.axf`。

- `demo/code/midterm_open_loop.c/.h`：公共 PWM 调度、限加速、降额和独立衰减纯函数。
- `demo/code/vision_control.c/.h`：摄像头转向与异常状态。
- `demo/code/vision_drive.c/.h`：方向/舵机映射、PWM 写入、PIT1 安全租约。
- `demo/code/vision_field.c/.h`：停车调参、完整候选配置原子验证。
- `demo/code/vision_debug.c`：USB/无线 UART 命令、文字日志、V2 图传。

## 停车调参

普通 ASCII，关闭 HEX 和自动发送，每行以 CRLF 结束。所有 @ 命令到达即停车，成功不会自动发车。

| 命令 | 含义 |
| --- | --- |
| `@motor cruise cap rise` | 公共开环 PWM 目标/硬上限/每秒增长上限；比例，不是车速 |
| `@balance scale1 scale2` | FIELD_3 新增，两路各自 0～1 的衰减；默认 1/1 |
| `@motor_dir level1 level2` | 配置已知实际前进极性，分别为 0 或 1；不猜测新接线 |
| `@gain kp kd kh` | 摄像头横向/微分/方向增益 |
| `@servo center min max sign` | 舵机中位/窄窗口，单位 µs，方向 ±1 |
| `@bands near_y far_y half` | 采样行带，归一化高度；修改后旧轴标定失效 |
| `@camera near_x far_x` | 已知居中直道两点参考轴，补偿安装偏移，不在未知弯道自动学习 |
| `@status` | 读回版本、配置、方向及 `[MOTOR] ... scale=.../...` |
| `!` | 任意解析状态停车 |

例如 `@balance 0.95 1` 只表示衰减 MOTOR1 的命令 5%，不表示它就是左轮、不表示轮速差 5%，也不是已经场地验证的推荐值。应根据你们的方向/振荡/出弯反馈逐次调整。

`tools/field_serial.ps1` 已识别 FIELD_3 和 balance 能力，仍拒绝向不支持该命令的旧版本发送。RUN 日志 `pwm` 是公共命令，乘以读回的 scale 才是各通道命令；不是编码器测量。

## 启动与安全边界

上电仍 DISARMED，电机 PWM 为零；需要有效配置、相机参考轴、连续有效帧和独立人工 `a` 才行驶。`h` 心跳不能延长相机帧有效期；参数更新、模式切换、图传和暂停都会撤输出。保持 100ms 帧龄、500ms 心跳、可配置单次运行租约及故障锁存；PIT1 不依赖前台视觉/串口及时运行来撤输出。

用户已观测的舵机中位 1550µs、窄窗口 1500～1600µs、方向 -1 保存在 `profiles/field-20261019.json`。它不是机械极限或动态验收结果。恢复工具仅写这些舵机/行带参数并强制电机零目标，不恢复旧相机轴、不猜电机极性、不启动小车。此次不再要求重复现场台架检查，但不会把未知配置冒充已验证。

复位后 RAM 参数丢失。不要把旧日志的图像坐标、PWM 或方向当成所有车辆的通用值。后续你们反馈实际现象及当时配置即可；需要进一步证据时再协商采集，不自动开展现场动作。

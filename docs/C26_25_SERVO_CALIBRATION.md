## 固件更新

版本为 `MIDTERM_C26_25`，工程仍为 `demo/mdk/midterm_switch.uvprojx`，目标 `nor_sdram_zf_dtcm`。

端点数值与C24相同。这次将其从“等待测量的默认窗口”确认为操作者实测标定，并使用明确的右端、中位、左端及方向常量配置；没有扩大已确认的机械范围。启动帮助信息新增：

```text
[ROUTE_SERVO] compiled right_us=1430 center_us=1550 left_us=1670 right_sign=-1; operator-confirmed static endpoints
```

这行报告编译内置参数；停车后若用 `@servo` 改RAM参数，以 `@status` 实际读回为准。C24的有符号前馈补偿、单边线速度档、动态电机功率、十字方向优先与圆环路径回退保持原策略。当前相机、速度环和整车行驶效果仍需实车验证。

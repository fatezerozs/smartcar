# 无线舵机端点实测记录（2026-10-22）

操作者在场观察，固件为 `MOTOR_THRESHOLD_DIAG_1`；无线端 COM10、115200/8N1，owner=radio。测试前操作者确认前轮悬空、驱动电机供电断开、保留舵机供电。软件每一步确认 C26=0/C27=1、mode=SERVO、控制器 DISARMED、faults=0，以及 cruise=cap=0。

## 观察结果

| 位置 | PWM 脉宽 | 证据 |
| --- | --- | --- |
| 右转极限 | 1430µs | 操作者在该档反馈“右转极限，可以了” |
| 中位 | 1550µs | 操作者反馈“转动至中位” |
| 左转极限 | 1670µs | 操作者在该档反馈“这算是左转极限了” |

方向已核对：大于中位向左，小于中位向右，与现有车体正方向为右、舵机 sign=-1 的配置一致。左右端点相对中位各为 120µs；这是指令脉宽范围，不是实测转角。

这些是本次静态、前轮卸载条件下的操作者观察端点，没有转角传感器、电流测量或加载行驶验证。没有继续推动机械端点，也没有将 500–2500µs 的电气试验范围当成机械可用范围。若用于持续行驶，端点应保留机械余量，例如向中位收回 10–20µs 后再验证；该建议尚未写入控制配置。

## 执行顺序

所有接受的动作均为单次 300ms 脉冲，最大相邻变化 50µs，结束后读回 active=0。

1. 1500：操作者反馈没有转动。
2. 1550：操作者确认中位。
3. 1570、1620、1670：逐步左转，逐档等待操作者反馈；1670 被确认左极限。
4. 沿 1620→1570→1550 分步回中，再测试 1500。
5. 1450、1430：逐档测试右转；1430 被确认右极限。
6. 结束后沿 1480→1530→1550 分步回中，读回 BENCH seq=14、value=1550、hold_ms=300、active=0，并发送 `!` 关闭输出。最后一个命令为中位，软件没有实际转角反馈，不能独立证明最终机械位置。

所有步骤均未发送电机动作或启动命令，也未执行 `@save`、修改赛道参数或烧录恢复赛道固件。车上目前仍是台架诊断固件；需要行驶前应另行恢复对应赛道固件。当前拨码最后读回为 SERVO，建议结束后将 C26/C27 均置 OFF。

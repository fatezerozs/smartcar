# FIELD_4：C12 开关、两秒启动、掉电保存

2026-10-19。用户确认没有普通 S1/S2 按键，要求将 C12 用作启动开关，并在上电约 2 秒启动。因此不使用原库 C15/C14，不接管核心板 MODE/RST。

此轮只修改、离线验证和编译，未连接串口、烧录、保存实车 Flash 或驱动车辆。板上此前是 FIELD_3；新 AXF 必须另行下载。

## 开关接线与操作

开关两端接 **C12 和信号 GND**，C12 内部上拉：接通到 GND 为开启，断开为停止。不要把 C12 接 5V、电池、电机端子或驱动功率地线；使用主板信号地。若实际开关有效电平相反，应修改 vision_profile.h 中 VISION_START_SWITCH_ACTIVE_LEVEL，不通过倒置电机极性修正。

- C12 断开：电机及舵机输出撤销，保持停车。
- 开机时 C12 已接通：恢复有效已保存参数，在主板启动计时约 2000ms 时尝试起步。
- 开机时 C12 断开：保持待机。断开状态保持至少 300ms，再接通；从本次接通开始等待 2000ms 尝试起步。
- 开启采用 30ms 稳定判定，关闭由 PIT1 每 10ms 原始采样直接撤 PWM，不等待视觉或串口主循环。它是软件停机，不是断电式硬件急停，也不保证机械停车距离。
- 已运行后断开，即停；不足 300ms 的抖动不会自动重新起步。要再次启动，先断开至少 300ms，再接通。
- 2 秒到时赛道无效、帧陈旧、配置不完整或存在锁存故障：本次拒绝起步，不排队等待人退开后突然补启动。纠正后需明确再次断开/接通，锁存故障须先通过 c 或 RST 清除。

**没有驱动板电源反馈。计时只能参考主板 MCU 启动，无法知道两个电源开关何时都打开。** 建议 C12 先断开，先开驱动板、再开主板，摆好后合上 C12。不要让主板先运行，再给驱动板突然上电。相机初始化超过启动期限时不会晚到补启动，可在准备好后重新切换 C12。

## 首次必须保存有效车辆配置

空白存储区不会凭空生成电机方向、PWM 或相机标定。仅烧录这一版，仍不能保证立即跑：首次需要把实际有效的车辆配置写入一次。配置不完整时 @save 明确拒绝，不设置假确认位。

1. C12 断开，停车设置车辆参数：@servo、@motor_dir、@bands、@camera、@gain、@motor，必要时 @balance 和 @duration。均沿用 FIELD_3 协议，ASCII 普通文本、整行 CRLF，不开启 HEX/自动发送。
2. @status 检查 ready=1、正确的脉宽/方向/相机参考轴及 PWM。ready 是配置资格，不代表当前帧一定有效；实际启动还会检查新鲜连续图像。
3. 停车发送：

```text
@startup 1 2000
@save
@status
```

4. 读回 [FIELD] OK; save 与 [STORE] valid=1、generation。保存只授权下次启动，不会在本次保存后立即发车。首次保存后重启主板，让启动链读回配置。
5. 下次上电恢复后，不再需要电脑发送 a/h。仍建议 C12 断开上电，再合上延时启动。

已观测舵机仅为本车中位 1550µs、保守窗口 1500～1600µs、right_sign=-1；不是机械极限或动态验收值。电机前进极性和起步 PWM 尚未由实车确认，最近非赛道画面也不能提供有效相机标定。本次没有制造这些未知参数，因此没有自动写入一份“可跑”的实车配置。

`@startup 0 2000` 再 `@save` 可关闭下次本地自动起步。`@load` 只恢复 RAM，停车且不安排当前启动，不等于 a。`@status` 等 @ 命令到达即停车；倒计时中任何操作者串口输入都会取消本次启动。图传、暂停、完整赛道观察模式均不能通过切换 C12 排队发车。

PC 工具支持 FIELD_4；保存需显式 `-SaveForAutostart`，提示保存配置可能在下次 C12 开启的上电中发车。默认只读，不自动保存。

## 不依赖电脑心跳，但保留异常管理

只有成功恢复保存配置、通过 C12 本地启动的运行源免远端 h 心跳。普通串口 a 仍为远程调试运行，继续要求 h，不能用一条普通参数命令永久取消全车心跳保护。

本地运行保留：视觉转向闭环、开环 PWM 上限/缓升/降额、100ms 帧龄、近带/行覆盖/数值检查、PIT1 独立撤输出和故障锁存。默认单次最长 **5000ms**；可停车设置 `@duration milliseconds`（100～60000ms）并保存，但不按运行时间编排路线。运行超时会停车，保持 C12 不会自动循环再次起步。

本地运行不输出周期 RUN 文本，避免脱离电脑或无线流控阻塞时让日志成为行驶依赖。串口仍能随时 !/s 停车；图传入口仍停止运动，不混入文字。

## 参数存储格式与恢复

链接器从整个 Flash 加载映像中保留最后两页：0x703FE000 和 0x703FF000，每页 4KiB。只这两个固定地址可写，禁止来自串口的任意 Flash 地址。参数层使用显式 64×32bit 字格式、版本、递增序号、CRC32 和全字段范围检查，不直接拷贝含填充字节的结构体，不保存活跃 arm、故障、临时心跳或倒计时。

保存只允许在停车且无故障/探测动作时执行；先写非当前页，再读回完整记录并核验 CRC。写入失败或掉电残缺时，仍可恢复上一有效页。相同配置重复保存不擦写。两个页都空白/损坏、IO 失败或记录版本不兼容时不启动。非本模块标识的未知非空页面拒绝擦除，不擅自覆盖旧程序数据。

板级适配明确处理原库 flash_write_page 实际使用 flash_union_buffer、from_buffer 包装错误总报成功的问题：先填缓存，调用直接函数检查返回，再独立读回校验；没有修改供应商驱动。该路径尚未实机写入验证，离线模拟不能代替电源完整性/真实 Flash 耐久验证。

RST/正常断电不应清除有效记录；但重新下载若选择整片擦除，会清除参数。不能承诺下载器任何擦除模式下都保留数据；重新下载后以 [STORE] 读回为准。不要把重新烧录旧版本当作撤销自动启动的唯一方法，应先断开 C12。

这是编码器故障下的受限中期控制，不提供车速、堵转、电流或欠压闭环，也不支持完整赛道自主环岛/十字处理；没有从斑马线自动计圈停车。

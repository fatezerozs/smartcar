## 修正与兼容边界

1. 初步识别ROUND_READY(0)：若当前双边中心可靠、当前几何有效，沿当前白色通道中心走；不再因为只是候选状态就强制使用固定半路宽。仅处理8->0、0->0，不在已确认入环时撤销任务。
2. GET_IN_READY(1)/GET_IN_ROUND(2)的转向和入口虚拟0/188语义保持；IN_ROUND(3)沿用V8原处理，未重选入口、重写环岛FSM、改机械端点或转向增益。新增修正在AGENTS.md写明本轮用户授权范围。
3. 原FSM进入出环4..7后：连续两个当前新帧都有可靠实测双边及当前白路，采用实际中心误差，替换固定半路宽/固定四分之一偏移造成的旧目标。允许合理回正或改变纠偏方向；若继续套用V8“必须保持旧舵向且至少85%偏转”，就无法修复居中出口仍满舵的问题。
4. 出环6/7已有原FSM资格时：当前出口外边+已学逐行宽度可直接形成单边出口目标，不必等两边同时恢复；左环要求当前右外边、右环要求当前左外边。出环4/5只在此前已取得可靠双边出口之后允许单边桥接。每帧白路/边界检查仍必须通过，不回放旧像素、没有盲目定时直走。
5. 单边出口以当前近端中心误差为主；远端航向贡献为0.25*(全段误差-近端误差)，限制在±8px，避免远处仍跟着圆弧的线把出口车身拉回环内。双边出口按当前实测双边中心的原行权重处理。该8px是待实车检验的候选量，不是地面米制参数。
6. 准备0/1仅靠边距限速时，目标下限为min(原请求,0.85m/s)。普通和沿环边距限制不取消。环岛内加速变化率0.6m/s²，准备降速0.8m/s²、其余边距降速2.5m/s²；每次时间步封顶100ms。零请求立即生效，C26/斑马线停车不经过慢速坡道。普通状态和普通启动保持原行为。

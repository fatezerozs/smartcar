1. **恢复可靠路宽。** 在普通状态、原始双侧真实边界上检查连续直路。近端至少28行、跨度30行，中心线/透视宽度可拟合且残差有限，旧宽偏差超过25%时，连续8帧一致后更新当前实测且符合拟合的行。检查在路口补线之前进行，推算/joined行、环岛状态、弯道或全白画面不能参与重学。没有清空有效模型或新增发车等待。已有正确路宽保持不变。

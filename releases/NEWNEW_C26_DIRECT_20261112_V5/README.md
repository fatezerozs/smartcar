## 实现

- Threshold.c/.h灰度直方图改32位；Deal_Init二值化采用>。原探边、环岛状态机不替换。
- 主循环误差计算拒绝视野外坐标及无效行；不再因middleline[0]缺失就跳过后续有效路径。
- Img_Deal在原始二值化后、调试绘制前保留current_road_mask，避免彩色叠画破坏通行判定。
- obstacle_path.h只在普通路/入环准备阶段检查两侧有白路、上下有闭合证据的小型内部暗区，要求8—60px宽、6—30行当前支持。环内/出环阶段不抢占原任务。大块岛形、整路暗带及普通道路作为负例。
- DP从当前近端足迹向远处求白路连接，每行检查约40%当前外边路宽+4px的完整车身包络，最大横向移动4px/行。40%是未做地面投影标定的图像包络起点，不能当作真实厘米安全余量或可实现曲率证明。
- 在同一当前障碍两侧通道间加入侧别连续性排序；上一方向只影响代价，所有路径像素每帧重算，不凭旧路径盲走。障碍贴近底部被裁切时，只有之前闭合确认且当前仍可见对应暗边的对象才能延续，防止尚未经过就取消避让。
- 优先跟踪当前绕行连接的误差，避让目标0.55m/s；其他路段按10—35px误差连续将1m/s降至0.65m/s，不用固定PWM增加驱动力。左右候选距离尺度和PI不变。
- 没有当前有效路线，或已确认障碍但没有能放下包络的当前通道时，目标置零；下一帧道路恢复可自动恢复，不增加故障锁死或新启动确认期。原斑马线停车行为保留。
- V4抑摆/大幅换向、1430/1550/1670us端点、50Hz、C26和硬件映射保持。正式NEWNEW_C26_V5遥测增加obs/blocked/side/lane，原COM15监听继续保存原始字节。
